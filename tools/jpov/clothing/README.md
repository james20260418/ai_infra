# JPOV 穿衣工具（clothing tool）使用说明

> 面向 **人类与 AI**。把一件（通常由 gen3d 生成的）衣服模型**对齐到人体**、**自动蒙皮**、
> 再**保存成带骨骼的 glb**。
> 代码：`tools/jpov/clothing/`（独立包 `jpov::clothing`）；编译脚本：`tools/jpov/clothing_tool.sh`
> （本说明即从该脚本引用）。

---

## 1. 一句话流程
**打开（人体 + 衣服）→ 对齐贴合 → 一键蒙皮 → 保存 glb。**

## 1.1 工具行为模型（状态与约定，读前必看）
- **几何真相**：`cloth_current_`（每 primitive 的当前 CPU 几何 + 材质）= 显示 / 仿真 / 保存的
  唯一真相；仿真 / 变换改它后推上 GPU，`sims_` 只是**驱动它**的软体仿真器。
- **蒙皮（skin）**：状态**记在 mesh 上**（`JOINTS_0/WEIGHTS_0`）。「有没有蒙皮」**现判 mesh
  内容**（本会话「一键蒙皮」或载入 glb 自带皆算）；它只影响「随机摆动是否带动衣服 / 保存是否写
  skin」，**不禁用任何编辑**。
- **松弛度（relax）**：结果存**工具内**（本会话「由固定点推导」或载入 glb 自带的 `_JPOV_RELAX`），
  **仅在保存时**写入 mesh 的 `_JPOV_RELAX`。勾「显示松弛度场」即可看——**只要当前有就有**，
  不要求本会话推导过。
- **只有「补洞」会改顶点数**：它会给新增顶点一并插值 `JOINTS/WEIGHTS/_JPOV_RELAX`；其余操作
  （平移 / 旋转 / 缩放 / 仿真 / 重置）都保顶点数 ⇒ 蒙皮 / 松弛后仍可继续编辑。
- **不做**：穿衣自动对齐 / 贴合（其余功能已接）。

## 2. 编译
```bash
cd <repo 根>
bash tools/jpov/clothing_tool.sh        # 编译到 output/jpov_clothing_tool/
```

## 3. 运行（示例：Mixamo 男性 + 战术背心，照抄即可试）
```bash
output/jpov_clothing_tool/jpov_clothing_tool \
  --body_reference_path tools/jpov/assets/models/characters/mixamo_male.glb \
  --cloth_path          tools/jpov/assets/models/clothing/harness_vest/harness_vest.glb
```
| 参数 | 说明 |
|---|---|
| `--body_reference_path <glb>` | 人体参考（**带骨架**）。缺省 = 项目自带 Mixamo 男性。 |
| `--cloth_path <glb>` | 衣服模型（**必填**）。 |
| `--phi_deg <度>` | 初始俯视角（默认 20）。 |
| `--bind_distance <m>` | 关联距离 d（米，默认 0.1）—— 决定仿真点集合与关联邻居表（见 §4）。 |
| `--motion_enable` | 启动即启用「随机摆动测试」（等价左下角勾选）。 |
| `--motion_phase <0~1>` | 主轴相位初值（**给了即启用**，便于 headless 出图）。 |
| `--motion_amp <0~90度>` | 关节幅度初值（按 5° 量化）。 |
| `--motion_seed <0~65535>` | 随机种子初值（换种子 = 换一套随机动作）。 |
| `--hole_fill` | headless 出图前跑一次补洞（脚本化验证，见 §4）。 |
| `--hole_perimeter <m>` | 补洞的「最大洞周长」阈值（米，默认 0.2；0 = 不限制）。 |
| `--derive_relax` | headless 出图前跑一次「由固定点推导松弛度」（见 §4.5）。 |
| `--relax_anchor_band <ymin> <ymax>` | 用世界 Y ∈ [ymin,ymax] 的顶点作「固定点」（headless；与画笔选区并集）。 |
| `--relax_radius <m>` | 松弛度饱和半径（米；0 = 自动定标，默认 0）。 |
| `--relax_max_lag <m>` | 逐顶点最大滞后位移 max_lag（米，默认 0.05）。 |
| `--show_relax_field` | 开启松弛度场可视化（headless 出图验证用）。 |
| `--save_cloth` | headless 出图前保存一次衣服 glb（脚本化验证 `_JPOV_RELAX` 落盘）。 |
| `--lag_enable` | 启用布料 **LAG**（整体平动的一阶/二阶延迟；等价左下角「开启 LAG」，见 §7.1）。 |
| `--lag_second_order` | 用**二阶**延迟（否则一阶）。 |
| `--lag_rise_ms <ms>` | 延迟追踪的上升时间（毫秒，默认 150）。 |
| `--lag_overshoot <frac>` | 二阶超调量（默认 0.2；仅二阶）。 |
| `--body_trans <x> <y>` | 整体平动（世界 m；人体 + 衣服）。 |
| `--lag_warmup_frames <n>` | headless 出图前先推进 N 帧并把平动 ramp 到目标（让 tracker 起滞后）。 |

交互：**右键 drag 旋转视角、滚轮 zoom、中键 drag 纵向平移（pan）**。

> **中键纵向 pan**：纵向拖 **半屏 = 相机注视点升降 1m**（世界坐标）；相机位置随注视点
> **同步平移**（朝向不变 ⇒ 纯平移，非旋转）。

## 4. 界面

> 除左上「变换 / 保存 / 场景」面板保持常驻外，其余面板均为**可折叠（Accordion）**：
> 点面板**标题栏**展开 / 收起，收起时只显示**标题栏**（标题常可见，便于识别）；
> **启动时默认全部折叠**。所有面板宽固定 **400px**（不随窗口宽缩放），仅按窗口尺寸贴边 / 居中锚定。
- **顶部中间 — 3D 画笔（选区）**：按钮 **画笔**（点一次 **激活**，再点 / **ESC** 结束）；滑条 **画笔半径 (px)**（5~200，默认 100）。
  **激活态**下鼠标周围画淡黄半透明圆（尺寸）；**左键**在非 UI 区拖 / 点即**涂抹** —— 把鼠标射线附近（半径按屏幕像素 → 世界换算）的衣服顶点选入**选区**（淡黄 2px 方块标记）。
  「鼠标在任一面板上」时画笔不显示、不生效（UI hover 不算画笔）。**激活态结束 = 选区清空**（选区生命周期 = 一次激活）。
  选区状态 = 衣服顶点 index（`brush_tool.h`；相机射线 / 投影见 `camera_projection.h`）——后续「选区内平移/旋转/缩放、LAG 系数、alpha 调整」都以此为基准。
- **顶部中间（画笔面板下方）— 顶点 Tint 覆盖（刷选区）**：**复用 3D 画笔的选区**——
  先在「3D 画笔」面板激活并涂出选区，再点三个按钮之一：**刷 Tint 1 / 刷 Tint 2 / 清除 (0)**，
  一键把**选区内所有顶点**的 `base_tint` 覆盖成该 id（0 = 不换色），并即时推上 GPU。
  没有独立涂抹模式、没有第二个画笔半径。状态行显示当前选区点数 / 上次结果。
- **顶部中间（再下方）— Tint 调色 / 显示**：**启用 tint 乘法** 开关 + 两通道各一条 **R/G/B（0~1）** + 当前色块
  （默认 Tint 1 = 红 / Tint 2 = 绿，加载带 tint 的 glb 立刻能看出分区）；
  勾选 **显示 tint 分区**（按调色板色画 2px 点）。与「刷选区」面板**分开**：这里只调颜色/显示，刷哪个通道由上面按钮决定。
  保存 glb 时写入自定义顶点属性 `_JPOV_TINT`（`UNSIGNED_BYTE SCALAR`）。**染白不在本工具做**
  （建模时把该区 baseColor 留白最自然）；渲染 = `baseColor × 调色板色`，开关关掉时**完全不做乘法**。
  详见 `docs/jpov_base_tint_design.md`。
  ✅ object3d / 静态实例 / 蒙皮三条路径都消费 tint；「随机摆动测试（lag 检测）」走蒙皮路径时，
  工具会把当前调色板写进 `SkinnedInstanceState::base_tint`（逐实例），tint 照常显示。
- **顶部中间（画笔面板下方）— 布料 LAG 松弛度**：按钮 **由固定点推导松弛度**；滑条 **松弛度半径 (m, 0=自动)** / **最大滞后位移 max_lag (m)**；勾选 **显示松弛度场（蓝=固定 红=自由）**。见 §4.5。
- **左上 — 变换 / 保存 / 场景**
  - 平移 X/Y/Z：步长输入框 + `<` `>` 按钮
  - 旋转 RX/RY/RZ：步长输入框（度）+ `<` `>` 按钮（绕轴逆时针）
  - 整体缩放：系数框 + `-` `+`
  - 按钮 **保存衣服 glb**
  - 地面高度滑条；勾选「显示人体 / 显示衣服」
  - *变换即时生效，仿真进行中也能调。*
  > **只作用于选区（有画笔选区时）**：当顶部 **3D 画笔存在选区**时，平移 / 旋转 / 缩放**只作用于被选中的顶点**，
  > 其余顶点不动；旋转 / 缩放的**枢轴 = 选区顶点包围盒中心**。画笔无选区时作用于**全体**（原行为）。
  > ⚠️ 选区变换属「几何编辑」，**不改力学参照、也不更新仿真器的关联邻居表**——见下方「用户须知」。
- **右上 — 软体仿真**：关联距离 d（米，见下）/ 重力 g / 总质量 M / 力系数 F / 衰减 k / 速度上限；人体排斥（开关 + buffer + 切向速度保留系数）；勾选 **显示力学参照网格**；继续/暂停、重置衣服。
  > **重置衣服** = 几何重置（回到启动姿态）**+ 材质重置**（base color alpha 回到启动样）；两者在后端分开实现。

  > **关联距离 d（米）**：仿真点的「缝合」半径 —— 决定①哪些顶点被视为「邻接」（`|v_j-v_i| ≤ d`，与拓扑无关），
  > ②长边加密的阈值。**拖它会重建仿真点集合**（几何回到启动姿态、仿真暂停）。
  > 默认 **0.1 m**；高密度 / 被缩放拉伸后的模型若接缝处出现裂缝，可调大 d 让两侧重新连上；
  > d 过大则会把不相干处也连起来（布料发硬）。与 `soft_mesh_viewer` 的「关联距离 d」同一物理量。
- **底部中间 — 补洞（推进法）**：按钮 **执行补洞**；勾选 **细分（匹配周围边长）** / **平滑（fairing）**；滑条 **最大洞周长 (m)**（默认 0.2，0 = 不限制）。
  **作用**：把网格里的破洞/裂缝补上（**在仿真关联之前**），避免缝合处仿真时开裂。
  算法为 Liepa 2003 风格的「边界环三角化」：先按位置焊接缝合重复点 → 找边界环 →
  最小面积 DP 三角化 → 可选细分 + fairing（见 `mesh_hole_fill.h`）。
  **最大洞周长**用来滤掉腰口/下摆/袖口这类「本来就该开」的大口（超过阈值的环不补）；
  **设 0 = 全补**（⚠️ 会把自然开口也封上，一般只在排查时用）。
- **右下 — 软布自动蒙皮**：按钮 **一键蒙皮**；勾选 **权重生长（种子扩散）**（默认开）；**种子半径(mm)**（默认 10）；勾选 **焊接用相对局部边长**（默认关 = 绝对距离）；焊接参数框（绝对模式为 **焊接容差(mm)** 默认 5；相对模式为 **焊接比例(×边长)** 默认 0.3）；按钮 **base color alpha 归一**（见下）。
- **左下 — 随机摆动测试**（贴左下角）：勾选 **启用**；按钮 **播放 / 暂停**；滑条 **主轴（相位）** / **关节幅度(°)**；输入框 **随机种子**（0~65535）（见 §7）。

### ⚠️ 用户须知

**① base color alpha 归一（右下蒙皮面板的按钮）**
- **作用**：把 **base color 贴图**的 alpha 通道置 1（不透明）——修补透明 / 镂空贴图被误抠出的「洞」
  （alpha < alphaCutoff 时 cutout 渲染会 discard，看起来就是镂空破洞）。
- **作用对象**：**被选中的顶点所围成的三角形**（三个顶点都被画笔选中的三角形）在 UV 上覆盖到的贴图区域；
  **画笔未选取时** → 整张贴图。
- 结果即时反映在视图里，且并入「**保存衣服 glb**」。**「重置衣服」会一并把它重置**（材质重置，见右上面板）。
- 没有 base color 贴图的 primitive 会跳过（无 alpha 可归一）。

**② 选区变换 vs 力学参照（重要）**
- 有画笔选区时，左侧平移 / 旋转 / 缩放**只作用于被选中的顶点**（旋转 / 缩放枢轴 = 选区顶点包围盒中心）。
- **力的参照网格 = 原始 mesh + 全体 scale / rotation**（不含选区变换、不含仿真形变）。即仿真的
  「关联动力学」只受**全体**操作影响，**选区（部分）变换不计入**。
  ⇒ 选区变换只改**当前几何**（用于定型 / 保存）；**开仿真时弹簧会把选区形变拉回参照形状**。
- **「显示力学参照网格」**（右上面板勾选）：把参照网格的原始顶点用**蓝色 2D 像素**画出，便于核对。
  参照响应全体旋转 / 缩放；平移时参照的包围盒中心总对齐实际 cloth 的包围盒中心。
- 「**重置衣服**」回到**启动**几何（丢弃选区变换）+ 原始贴图。

**③ 仿真焊接（缝不裂）**
- 与蒙皮面板的「焊接容差」**不同**：这是**仿真器**的焊接（方案 B）——把**位置重合的顶点在仿真里并成一个质点**，
  Step / 变换后把该点位置写回组内**所有**原始顶点 ⇒ 缝合缝**永远不会裂开**（此前的「碎了裂缝」根因）。
- 默认容差 **0.1 mm**（只并真正重合的缝合点）。⚠️ 必须**远小于顶点间距**：实测本资产顶点间距中位数 ~6mm，
  容差 0.02 m 就会把整件并成 **1 个点**。CLI `--weld_tolerance <m>` 可覆盖。
- 输出 mesh 的**顶点数 / 拓扑 / 属性不变**（只是组内顶点逐帧保持重合），因此法线、UV、蒙皮权重都仍然合法。

## 4.5 布料 LAG 松弛度（由固定点自动推导）

**是什么**：批次 LAG 副运动（见 `docs/jpov_instance_attr_lag_design.md`）需要逐顶点的「**松弛度**」
`lag_ratio ∈ [0,1]`（顶点属性 `loc6` / mesh 的 `kRelax`）：**0** = 顶点完全跟随当前 pose
（绷在身体上、不摆动），**1** = 完全滞后（自由摆动）。本面板把这个标注**自动化**。

**怎么用**：
1. **标固定点**：用 **3D 画笔**（顶部中间）涂抹衣服上「缝死不动」的点（如裙子的腰口）。
2. 点 **由固定点推导松弛度**（见 `relax_derive.h`）→ 工具按**测地距离**（沿网格表面的最短路）
   从固定点向外生长：离固定点越远松弛度越大，直到饱和到 1；再做一次 Laplacian 平滑去掉
   「测地脊线」的高频拐角（设计 §4.4 要求松弛度场低频）。
3. 勾选 **显示松弛度场** → 顶点用 2D 像素着色：**蓝 = 固定(0)**，**红 = 自由(1)**，核对过渡是否自然。
4. **保存衣服 glb** → 逐顶点松弛度写入自定义顶点属性 **`_JPOV_RELAX`**（`VEC2 = (lag_ratio, max_lag)`）。

**参数**：
| 参数 | 默认 | 含义 |
|---|---|---|
| 松弛度半径 (m) | 0（自动） | 松弛度饱和（升到 1）的测地距离；0 = 用到最远顶点的测地距离自动定标 |
| 最大滞后位移 max_lag (m) | 0.05 | 逐顶点「相对当前 pose 的最大允许位移」（设计 §4.4 的限幅，防时间性拉伸）；此值填给所有顶点 |

**要点 / 边界**：
- 固定点 = **画笔选区**（可多 primitive）∪ 可选「高度带」；无固定点的 primitive 跳过（不动）。
- 先**按位置焊接缝合重复点**（缝合缝两侧当同一点，容差 = 仿真焊接容差）→ 缝两侧松弛度**一致**，
  不会因 UV / 材质缝合处顶点被拆开而在缝上突变（驱动 LAG 时会撕裂）。
- **不连通**（与任何固定点无路径）的顶点 → 松弛度 **1**（没有东西约束它）。
- 变换 / 仿真**不改顶点 index** ⇒ 推导结果持续有效；**补洞**等改顶点数的操作会使结果失效
  （保存 / 显示时自动跳过，重新推导即可）。
- ⚠️ 底层 VS **尚未消费** `aRelax`（见 PR #169「只铺接口」）⇒ 推导 / 保存**不改变当前渲染外观**；
  它的作用是产出「带松弛度标注的资产」，等 LAG 渲染上线即可用。
- **重开自带数据**：载入的 glb 若**自带** `_JPOV_RELAX`（`kRelax`），工具直接读回 ——
  勾 **显示松弛度场** 即可看，**无需**本次会话重新推导（展示只认「当前 mesh 里有没有」）。
- **误点无害**：无固定点（画笔无选区且未设高度带）时点「由固定点推导松弛度」**不改变**已有
  结果（只提示），避免误点丢掉载入 / 已推导的松弛度。

## 5. 推荐操作顺序
1. 运行（§3）。
2. 用左上变换把**衣服对齐、贴合到人体**（后续蒙皮质量的前提）。
3. （可选）用右上仿真让衣服自然贴合 / 下垂。
4. （可选）底部中间 **执行补洞**，先把网格破洞/裂缝补上（仿真的关联邻居表基于它建）。
5. （可选）**标定固定点 → 推导松弛度**：先用 **3D 画笔**涂抹衣服上「绷在身体上、不摆动」的点
   （如腰口），再点顶部中间 **由固定点推导松弛度**；勾选 **显示松弛度场** 核对蓝→红过渡（见 §4.5）。
6. 右下 **一键蒙皮**。蒙皮后仍可继续变换 / 仿真（都保顶点数 ⇒ 权重↔顶点对应不破坏）；
   只有 **补洞** 这类改顶点数的操作会与已有权重 / 松弛度冲突（新顶点无权重，工具会一并处理）。
7. **保存衣服 glb** → 结果写在**源衣服同目录**，文件名 `<原名>_cloth_edit<时间戳>.glb`
   （已推导松弛度时写入自定义顶点属性 `_JPOV_RELAX = (lag_ratio, max_lag)`）。
8. （可选）左下角 **启用随机摆动测试 → 播放**，看衣服是否跟着人体动（见 §7）。

## 6. 蒙皮参数（右下）
| 参数 | 默认 | 含义 |
|---|---|---|
| 权重生长（种子扩散） | 开 | 种子冻结的调和扩散：离体顶点从种子「生长」出权重；关掉 = 只用逐顶点直接投影权重 |
| 种子半径 seed_eps (mm) | 10 | 到身体距离 ≤ 该值视为「贴身」→ **种子**（权重冻结）；更远的离体顶点由生长补出 |
| 焊接模式 | 绝对距离 | 勾选「焊接用相对局部边长」则改判据（见下） |
| 焊接容差 (mm) | 5 | **绝对模式**：相距 ≤ 该值的顶点视为同一「缝合点」→ 焊接成组，消除接缝**开裂** |
| 焊接比例 (×边长) | 0.3 | **相对模式**：相距 < 该比例 × 局部边长 才算「缝合点」 |

- **两种焊接判据**：
  - **绝对距离（默认）**：对一个固定阈值调参；简单，但**模型缩放/拉伸后要重调**（阈值是绝对毫米）。
  - **相对局部边长**：判据是「相距 < 比例 × 局部边长」。缝合重复点的距离 ≈0、真实相邻点 ≈1×局部边长，
    两者之间有大空档，所以该判据**与模型尺度、局部密度都无关**——把衣服拉伸/缩放后**不用重调**，
    密处（局部边长短）用小阈值、疏处用大阈值。推荐先试 `0.3` 左右。
- **衣服表面开裂** → 绝对模式调大「焊接容差」（5mm 实测更优），或改用相对模式（推荐）。
- **密集区被焊死 / 布料发硬** → 说明阈值过大；改用相对模式并调小比例（如 0.2~0.3）。
- **离体/悬空处权重乱**（种子太少、生长范围过大）→ 视情况调「种子半径」。

## 7. 随机摆动测试（验证「衣服会不会跟着人体动」）
让参考人体做一段**程序化随机动作**，看蒙皮过的衣服是否逐帧跟随（**不需任何外部动画资产**）。

- **启用**：左下角勾选「启用（真骨架蒙皮驱动人体）」。*衣服**带蒙皮**时动作才带动衣服；*
  *未蒙皮时动作不带动衣服*（状态行会写「衣服未蒙皮：动作不带动衣服」）。
  蒙皮可来自本次会话 **一键蒙皮**，也可来自**载入 glb 自带的** `JOINTS_0`/`WEIGHTS_0`（`kJoints`）
  —— 后者为重开成品资产时「直接能看效果」（不要求先在本次会话蒙皮一次）。
- **主轴（相位）**：一个周期 ∈ [0,1)。**播放时自动上升**（按固定速度推进、到 1 回绕，周期函数保证无缝）；
  **暂停时可拖动**这个滑条查看任意时刻的动作。
- **关节幅度 (°)**：每个关节的最大摆角（按 5° 量化）。
- **随机种子**：输入框（**0~65535**，输入完失焦/回车即 clamp），**换一个值 = 换一套随机动作**
  （重烘焙该种子的姿态集）。
- 播放速度固定（不做滑条）——快慢不影响判断蒙皮效果。

## 7.1 布料 LAG（副运动 = 整体平动的一阶/二阶延迟；2026-10-12）
> **方向（Danis）**：**不做 pose 的 lag**（pose 差值脱离不了动作幅度、裙子会匀速飘很诡异、用户难用）；
> 先做**用户能用的维度**：整体**平动（translation）**（partial rotation 的 lag 引擎保留、**未接入工具**）。

左下角「随机摆动测试」面板：
- **整体平动 X/Y (m，±2)**：人体 + 衣服的**世界平移**（先让人体能动起来）。
- **开启 LAG**：布料按「整体平动」的**一阶/二阶延迟**滞后 —— 用 `SkeletonPose.root_offset` 承载平动、
  跑 `interface/skeleton_motion_lag.h` 的 tracker，滞后量 → 布料 per-instance `pos_lag`，蒙皮 VS 按
  `_JPOV_RELAX` 松弛度 `mix` ⇒ 松的部分拖尾（**裙摆「飘起」**）、贴身部分跟随。
  **一阶**（`FirstOrderLagTracker`，rising time）无过冲；**二阶**（`SecondOrderLagTracker`，rising time
  + overshoot）有摆动/过冲。
- **需布料模型自带 `_JPOV_RELAX`** 才有效果（否则松弛度全 0、mix 恒等）。用 §4.5 推导后保存，或直接用
  `lace_skirt_skinned_relaxed_sample.glb`（§8）。**关 LAG 时 `pos_lag=0` ⇒ 视觉零变化。**

> 引擎侧：`SkinnedInstanceState` 的 `pos_lag`(loc15) / `partial_rotations_lag`(loc14) 由蒙皮 VS 在
> **mesh 带 `kRelax`** 时消费；**pose 的 lag 机制已移除**（不再有 `pose_*_lag` / loc11 的 pose_lag id）。

**为什么不需要重定向**：不同 Mixamo 源的 bind 姿态（T-pose/A-pose）、骨轴 roll、层级都可能不同，
导入**外部动画**才需要重定向；本方案在**目标骨架自己的关节局部空间**里直接生成姿态
（identity pose = 该骨架自己的 T-pose），故**完全不涉及重定向**（见 `random_pose_driver.h`）。

**headless 出图 / 回归**（脚本化验证，无需窗口）：
```bash
# 人体 + 背心 → 自动蒙皮 → 摆到主轴 0.3、幅度 45° → 出图
... --auto_skin --motion_phase 0.3 --motion_amp 45 --ui_shot --output_dir /tmp/ui
```
（不蒙皮、只给 `--motion_phase` 时：人体会摆、衣服保持静止——正是「衣服没蒙皮则不用动」的预期行为。）
