# JPOV 穿衣工具（clothing tool）使用说明

> 面向 **人类与 AI**。把一件（通常由 gen3d 生成的）衣服模型**对齐到人体**、**自动蒙皮**、
> 再**保存成带骨骼的 glb**。
> 代码：`tools/jpov/clothing/`（独立包 `jpov::clothing`）；编译脚本：`tools/jpov/clothing_tool.sh`
> （本说明即从该脚本引用）。

---

## 1. 一句话流程
**打开（人体 + 衣服）→ 对齐贴合 → 一键蒙皮 → 保存 glb。**

## 2. 编译
```bash
cd <repo 根>
bash tools/jpov/clothing_tool.sh        # 编译到 output/jpov_clothing_tool/
```

## 3. 运行（示例：Mixamo 男性 + 战术背心，照抄即可试）
```bash
output/jpov_clothing_tool/jpov_clothing_tool \
  --body_reference_path tools/jpov/assets/models/characters/mixamo_male.glb \
  --cloth_path          tools/jpov/assets/models/clothing/harness_vest/harness_vest.glb
```
| 参数 | 说明 |
|---|---|
| `--body_reference_path <glb>` | 人体参考（**带骨架**）。缺省 = 项目自带 Mixamo 男性。 |
| `--cloth_path <glb>` | 衣服模型（**必填**）。 |
| `--phi_deg <度>` | 初始俯视角（默认 20）。 |
| `--bind_distance <m>` | 关联距离 d（米，默认 0.1）—— 决定仿真点集合与关联邻居表（见 §4）。 |
| `--motion_enable` | 启动即启用「随机摆动测试」（等价左下角勾选）。 |
| `--motion_phase <0~1>` | 主轴相位初值（**给了即启用**，便于 headless 出图）。 |
| `--motion_amp <0~90度>` | 关节幅度初值（按 5° 量化）。 |
| `--motion_seed <0~65535>` | 随机种子初值（换种子 = 换一套随机动作）。 |
| `--hole_fill` | headless 出图前跑一次补洞（脚本化验证，见 §4）。 |
| `--hole_perimeter <m>` | 补洞的「最大洞周长」阈值（米，默认 0.2；0 = 不限制）。 |

交互：**右键 drag 旋转视角、滚轮 zoom、中键 drag 纵向平移（pan）**。

> **中键纵向 pan**：纵向拖 **半屏 = 相机注视点升降 1m**（世界坐标）；相机位置随注视点
> **同步平移**（朝向不变 ⇒ 纯平移，非旋转）。

## 4. 界面
- **顶部中间 — 3D 画笔（选区）**：按钮 **画笔**（点一次 **激活**，再点 / **ESC** 结束）；滑条 **画笔半径 (px)**（5~200，默认 100）。
  **激活态**下鼠标周围画淡黄半透明圆（尺寸）；**左键**在非 UI 区拖 / 点即**涂抹** —— 把鼠标射线附近（半径按屏幕像素 → 世界换算）的衣服顶点选入**选区**（淡黄 2px 方块标记）。
  「鼠标在任一面板上」时画笔不显示、不生效（UI hover 不算画笔）。**激活态结束 = 选区清空**（选区生命周期 = 一次激活）。
  选区状态 = 衣服顶点 index（`brush_tool.h`；相机射线 / 投影见 `camera_projection.h`）——后续「选区内平移/旋转/缩放、LAG 系数、alpha 调整」都以此为基准。
- **左上 — 变换 / 保存 / 场景**
  - 平移 X/Y/Z：步长输入框 + `<` `>` 按钮
  - 旋转 RX/RY/RZ：步长输入框（度）+ `<` `>` 按钮（绕轴逆时针）
  - 整体缩放：系数框 + `-` `+`
  - 按钮 **保存衣服 glb**
  - 地面高度滑条；勾选「显示人体 / 显示衣服」
  - *变换即时生效，仿真进行中也能调。*
  > **只作用于选区（有画笔选区时）**：当顶部 **3D 画笔存在选区**时，平移 / 旋转 / 缩放**只作用于被选中的顶点**，
  > 其余顶点不动；旋转 / 缩放的**枢轴 = 选区顶点包围盒中心**。画笔无选区时作用于**全体**（原行为）。
  > ⚠️ 选区变换属「几何编辑」，**不改力学参照、也不更新仿真器的关联邻居表**——见下方「用户须知」。
- **右上 — 软体仿真**：关联距离 d（米，见下）/ 重力 g / 总质量 M / 力系数 F / 衰减 k / 速度上限；人体排斥（开关 + buffer + 切向速度保留系数）；勾选 **显示力学参照网格**；继续/暂停、重置衣服。
  > **重置衣服** = 几何重置（回到启动姿态）**+ 材质重置**（base color alpha 回到启动样）；两者在后端分开实现。

  > **关联距离 d（米）**：仿真点的「缝合」半径 —— 决定①哪些顶点被视为「邻接」（`|v_j-v_i| ≤ d`，与拓扑无关），
  > ②长边加密的阈值。**拖它会重建仿真点集合**（几何回到启动姿态、仿真暂停）。
  > 默认 **0.1 m**；高密度 / 被缩放拉伸后的模型若接缝处出现裂缝，可调大 d 让两侧重新连上；
  > d 过大则会把不相干处也连起来（布料发硬）。与 `soft_mesh_viewer` 的「关联距离 d」同一物理量。
- **底部中间 — 补洞（推进法）**：按钮 **执行补洞**；勾选 **细分（匹配周围边长）** / **平滑（fairing）**；滑条 **最大洞周长 (m)**（默认 0.2，0 = 不限制）。
  **作用**：把网格里的破洞/裂缝补上（**在仿真关联之前**），避免缝合处仿真时开裂。
  算法为 Liepa 2003 风格的「边界环三角化」：先按位置焊接缝合重复点 → 找边界环 →
  最小面积 DP 三角化 → 可选细分 + fairing（见 `mesh_hole_fill.h`）。
  **最大洞周长**用来滤掉腰口/下摆/袖口这类「本来就该开」的大口（超过阈值的环不补）；
  **设 0 = 全补**（⚠️ 会把自然开口也封上，一般只在排查时用）。
- **右下 — 软布自动蒙皮**：按钮 **一键蒙皮**；勾选 **权重生长（种子扩散）**（默认开）；**种子半径(mm)**（默认 10）；勾选 **焊接用相对局部边长**（默认关 = 绝对距离）；焊接参数框（绝对模式为 **焊接容差(mm)** 默认 5；相对模式为 **焊接比例(×边长)** 默认 0.3）；按钮 **base color alpha 归一**（见下）。
- **左下 — 随机摆动测试**（贴左下角）：勾选 **启用**；按钮 **播放 / 暂停**；滑条 **主轴（相位）** / **关节幅度(°)**；输入框 **随机种子**（0~65535）（见 §7）。

### ⚠️ 用户须知

**① base color alpha 归一（右下蒙皮面板的按钮）**
- **作用**：把 **base color 贴图**的 alpha 通道置 1（不透明）——修补透明 / 镂空贴图被误抠出的「洞」
  （alpha < alphaCutoff 时 cutout 渲染会 discard，看起来就是镂空破洞）。
- **作用对象**：**被选中的顶点所围成的三角形**（三个顶点都被画笔选中的三角形）在 UV 上覆盖到的贴图区域；
  **画笔未选取时** → 整张贴图。
- 结果即时反映在视图里，且并入「**保存衣服 glb**」。**「重置衣服」会一并把它重置**（材质重置，见右上面板）。
- 没有 base color 贴图的 primitive 会跳过（无 alpha 可归一）。

**② 选区变换 vs 力学参照（重要）**
- 有画笔选区时，左侧平移 / 旋转 / 缩放**只作用于被选中的顶点**（旋转 / 缩放枢轴 = 选区顶点包围盒中心）。
- **力的参照网格 = 原始 mesh + 全体 scale / rotation**（不含选区变换、不含仿真形变）。即仿真的
  「关联动力学」只受**全体**操作影响，**选区（部分）变换不计入**。
  ⇒ 选区变换只改**当前几何**（用于定型 / 保存）；**开仿真时弹簧会把选区形变拉回参照形状**。
- **「显示力学参照网格」**（右上面板勾选）：把参照网格的原始顶点用**蓝色 2D 像素**画出，便于核对。
  参照响应全体旋转 / 缩放；平移时参照的包围盒中心总对齐实际 cloth 的包围盒中心。
- 「**重置衣服**」回到**启动**几何（丢弃选区变换）+ 原始贴图。

**③ 仿真焊接（缝不裂）**
- 与蒙皮面板的「焊接容差」**不同**：这是**仿真器**的焊接（方案 B）——把**位置重合的顶点在仿真里并成一个质点**，
  Step / 变换后把该点位置写回组内**所有**原始顶点 ⇒ 缝合缝**永远不会裂开**（此前的「碎了裂缝」根因）。
- 默认容差 **0.1 mm**（只并真正重合的缝合点）。⚠️ 必须**远小于顶点间距**：实测本资产顶点间距中位数 ~6mm，
  容差 0.02 m 就会把整件并成 **1 个点**。CLI `--weld_tolerance <m>` 可覆盖。
- 输出 mesh 的**顶点数 / 拓扑 / 属性不变**（只是组内顶点逐帧保持重合），因此法线、UV、蒙皮权重都仍然合法。

## 5. 推荐操作顺序
1. 运行（§3）。
2. 用左上变换把**衣服对齐、贴合到人体**（后续蒙皮质量的前提）。
3. （可选）用右上仿真让衣服自然贴合 / 下垂。
4. （可选）底部中间 **执行补洞**，先把网格破洞/裂缝补上（仿真的关联邻居表基于它建）。
5. 右下 **一键蒙皮**。*蒙皮后几何冻结*（禁变换 / 仿真 / 重置）—— 想改就重开。
6. **保存衣服 glb** → 结果写在**源衣服同目录**，文件名 `<原名>_cloth_edit<时间戳>.glb`。
7. （可选）左下角 **启用随机摆动测试 → 播放**，看衣服是否跟着人体动（见 §7）。

## 6. 蒙皮参数（右下）
| 参数 | 默认 | 含义 |
|---|---|---|
| 权重生长（种子扩散） | 开 | 种子冻结的调和扩散：离体顶点从种子「生长」出权重；关掉 = 只用逐顶点直接投影权重 |
| 种子半径 seed_eps (mm) | 10 | 到身体距离 ≤ 该值视为「贴身」→ **种子**（权重冻结）；更远的离体顶点由生长补出 |
| 焊接模式 | 绝对距离 | 勾选「焊接用相对局部边长」则改判据（见下） |
| 焊接容差 (mm) | 5 | **绝对模式**：相距 ≤ 该值的顶点视为同一「缝合点」→ 焊接成组，消除接缝**开裂** |
| 焊接比例 (×边长) | 0.3 | **相对模式**：相距 < 该比例 × 局部边长 才算「缝合点」 |

- **两种焊接判据**：
  - **绝对距离（默认）**：对一个固定阈值调参；简单，但**模型缩放/拉伸后要重调**（阈值是绝对毫米）。
  - **相对局部边长**：判据是「相距 < 比例 × 局部边长」。缝合重复点的距离 ≈0、真实相邻点 ≈1×局部边长，
    两者之间有大空档，所以该判据**与模型尺度、局部密度都无关**——把衣服拉伸/缩放后**不用重调**，
    密处（局部边长短）用小阈值、疏处用大阈值。推荐先试 `0.3` 左右。
- **衣服表面开裂** → 绝对模式调大「焊接容差」（5mm 实测更优），或改用相对模式（推荐）。
- **密集区被焊死 / 布料发硬** → 说明阈值过大；改用相对模式并调小比例（如 0.2~0.3）。
- **离体/悬空处权重乱**（种子太少、生长范围过大）→ 视情况调「种子半径」。

## 7. 随机摆动测试（验证「衣服会不会跟着人体动」）
让参考人体做一段**程序化随机动作**，看蒙皮过的衣服是否逐帧跟随（**不需任何外部动画资产**）。

- **启用**：左下角勾选「启用（真骨架蒙皮驱动人体）」。*衣服必须先**一键蒙皮**，动作才会带动衣服；
  未蒙皮时动作不带动衣服*（状态行会写「衣服未蒙皮：动作不带动衣服」）。
- **主轴（相位）**：一个周期 ∈ [0,1)。**播放时自动上升**（按固定速度推进、到 1 回绕，周期函数保证无缝）；
  **暂停时可拖动**这个滑条查看任意时刻的动作。
- **关节幅度 (°)**：每个关节的最大摆角（按 5° 量化）。
- **随机种子**：输入框（**0~65535**，输入完失焦/回车即 clamp），**换一个值 = 换一套随机动作**
  （重烘焙该种子的姿态集）。
- 播放速度固定（不做滑条）——快慢不影响判断蒙皮效果。

**为什么不需要重定向**：不同 Mixamo 源的 bind 姿态（T-pose/A-pose）、骨轴 roll、层级都可能不同，
导入**外部动画**才需要重定向；本方案在**目标骨架自己的关节局部空间**里直接生成姿态
（identity pose = 该骨架自己的 T-pose），故**完全不涉及重定向**（见 `random_pose_driver.h`）。

**headless 出图 / 回归**（脚本化验证，无需窗口）：
```bash
# 人体 + 背心 → 自动蒙皮 → 摆到主轴 0.3、幅度 45° → 出图
... --auto_skin --motion_phase 0.3 --motion_amp 45 --ui_shot --output_dir /tmp/ui
```
（不蒙皮、只给 `--motion_phase` 时：人体会摆、衣服保持静止——正是「衣服没蒙皮则不用动」的预期行为。）

## 8. 成品样例（成功典范，已入库）
两个「对齐 → 蒙皮 → 保存」的**标准成品**（带 skin / 24 骨），作「正确结果」参考与回归对照：
- `tools/jpov/assets/models/clothing/harness_vest/harness_vest_skinned_sample.glb`
  —— 战术背心，对齐到 mixamo_male。
- `tools/jpov/assets/models/clothing/yoga_pants/yoga_pants_skinned_sample.glb`
  —— 瑜伽裤：先经 **model editor** 沿水平面裁掉裤腿下方（开个口），再对齐 mixamo_male +
  一键蒙皮，焊接用**相对局部边长 0.3**。

查看（任选一个成品）：
```bash
output/jpov_clothing_tool/jpov_clothing_tool \
  --body_reference_path tools/jpov/assets/models/characters/mixamo_male.glb \
  --cloth_path tools/jpov/assets/models/clothing/yoga_pants/yoga_pants_skinned_sample.glb
```
（也可用任意 glTF 查看器 / Blender / fbx_viewer 打开；带 skin，可直接接渲染管线。）

### 经验（2026-10-06 Danis）
- **焊接用「相对局部边长」更合适**：与缩放 / 密度无关、拉伸后免调；实测 **0.3** 效果迄今最好。
- **配合 model editor 事半功倍**：先在 model editor 里裁剪（如给瑜伽裤裤腿开个口）——
  裁剪会按插值补出边界顶点、带好法线/UV/骨权；再到本工具对齐 + 蒙皮，比在蒙皮阶段硬补救省事得多。

## 9. 边界
- 面向**贴身软布**；宽松 / 叠穿非本工具目标（离体顶点靠生长 + 兜底）。
- 蒙皮后**几何冻结**，权重↔顶点对应不可再变。
- 结果 glb 含 skin + inverseBindMatrices，直接在 fbx_viewer / 渲染管线使用。
