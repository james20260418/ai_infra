# JPOV ARAP 软体查看器（arap_viewer）设计说明

> 状态：分支 `feature/20260922-jpov-arap-viewer`（本地提交，未 push）。
> 作者：James（2026-09-22 首版；2026-09-23 按需求方指示恢复为「四参数最简模型」）。
> 目标：把「衣物自动贴合人模」这条链路里**动力学仿真**那一环先落地成可交互验证的工具。

---

## 1. 目标与非目标

**目标**

1. 一个与 `jpov_model_viewer` **并列**的交互式查看器：能加载 glb、调视角/光照/地面高度。
2. 额外提供**软体动力学**：把网格当作可变形软体，在重力场里从高处摔到地面，观察形变。
3. 交代清楚「CPU 网格变形后，法线/切线怎么办」。
4. 物理模型**只有需求方指定的四个参数**（胡克 h / 重力 g / ARAP b / 阻尼 u），
   全部可在面板上实时调；界面另暴露光照与地面高度。

**非目标**

- 不接骨骼/蒙皮（那是 `jpov_clothes_rig_design.md` 的 weight transfer 一环）。
- 不做自碰撞（衣服 vs 衣服）、不做真实人体碰撞（地面是平面）。
- **不做 bending（弯曲刚度）**、不做体积保持、不做摩擦 —— 四参数模型里没有它们
  （2026-09-23 需求方指示：先把最简模型跑通，塌陷就定位问题根因，不要靠加因子掩盖）。

## 3. 力的模型（四参数，2026-09-23 需求方指定）

质点质量**全部 m = 1**，F = m·a，一共只有四个力：

```
① 胡克弹簧（每条边一根，三角形三条边都要）：F = −k_e·(L − L0)·û ,  k_e = hooke / L0
② 重力 g
③ ARAP 局部形状力：F_i = b·(goal_i − x_i) ,  goal_i = c_i + R_i·(rest_i − rest_c_i)
④ 线性阻尼：F_i = −u·v_i
```

积分：**显式（半隐式）欧拉**，固定步长（需求方指定 0.05 s）：
`v ← v + (F/m)·h ;  x ← x + v·h`（m = 1）。渲染帧 1/60 s 用累加器凑够 0.05 s 才推进一步。

地面：`y = ground_y` 水平面，**位置硬约束 + 法向速度归零**（完全非弹性）。
它是边界条件、不是力，所以不带"刚度"参数；四参数模型里也没有切向摩擦。

### 3.1 为什么胡克系数要"按初始边长归一化"（k_e = h/L0）

把一条长边 L 细分成 n 段（每段原长 L0 = L/n、k_e = n·h/L），n 根**串联**后的等效刚度

```
k_串 = k_e / n = h / L
```

**与 L 无关、也与"分了几段"无关** ⇒ 同一个物理物体无论网格多细，宏观刚度一致。
`L = L0`（初始长度）处力为零 —— 原长就是力的零点。

### 3.2 ARAP 局部形状力

出处：Müller et al. 2005《Meshless Deformations Based on Shape Matching》，
与 Sorkine & Alexa 2007 的 ARAP 同源。「局部」是关键：**不是拉回原始世界坐标**，
而是把每个质点的 1-ring 邻域拉回「原始形状经该邻域最优旋转后的样子」。
`R_i` 由协方差 `A = Σ (x_j−c_i)⊗(rest_j−rest_c_i)` 的**极分解**得到
（Higham 迭代 `R ← ½(R+R⁻ᵀ)`，先按 Frobenius 范数归一化）。

⇒ 整个物体可任意平移/旋转而形状代价为零；**只有拉伸/压扁才付力**。
注意：ARAP **不抵抗等距变形（弯曲/折叠）** —— 这是它的定义性质，见 §7。

### 3.3 力的计算是「状态的纯函数」

`ArapSim::ComputeForcesAt(positions, velocities, out)` 只读、不改状态；`Step` 内部就是
「算力 → 积分 → 地面」。这样力律**能被单测直接验证**（在已知构型上比对解析力），
而不是只能"跑一步看位移"间接推断。

## 4. 拓扑：物理用「焊接」，渲染用「不焊接」

| 用途 | 拓扑 | 为什么 |
|---|---|---|
| **物理**（弹簧/ARAP/地面） | **按位置焊接**（ε = 1e-6，仅在 bind pose 判定一次） | UV 缝两侧的顶点几何上是同一表面点；不焊接会被弹簧力拉开成**裂缝** |
| **渲染**（法线/切线） | **不焊接**（按顶点索引取邻域） | 顶点分裂是数据的一部分：硬边靠它保留（反例：直棱柱三条棱交会处一个位置三个顶点，法线分别是上/左/右面） |

**多 primitive = 同一个物理物体**：焊接跨 primitive 进行（资产常按材质切开，
如 lantern.glb = 杆/链/灯罩），接缝处位置重合的顶点焊成同一质点 ⇒ 各部件互相支撑；
若各自独立仿真，各部件互不支撑、看起来像模型散架（2026-09-22 实测）。

## 5. 变形后法线/切线怎么办

**不"补"，也不"旋转旧值"——每帧用变形后的位置重跑同一个函数。**

```
Step() → WriteBackPositions() → RecomputeTangentSpace() → UpdateMesh() → Draw()
```

- **法线**：面叉乘 → 面积加权累加到顶点 → 归一化（按**索引**，不焊接）。
- **切线**：`T = ∂P/∂u`，用变形后位置 + 不变 UV 解 2×2 方程，公式与
  `obj_loader.cc` / `gltf_loader.cc` 逐字一致（同源，不产生第二套约定）。
- **B 不存**（shader 内 `cross(N,T)`）；**法线贴图无需处理**（切线空间相对方向 + UV 不变）。

## 6. 相机、UI 与 headless

- **取景**：球面角相机目标点下移到「模型顶 ↔ 地面」中点，按所需垂直半跨度反推 R。
- **UI**：顶部 2 按钮（动力学启停 / 重置 mesh）+ 状态文本（质点数 / 边长畸变 / 形状力 /
  退化旋转 / 子步数）；底部**左列** 4 个光照·标高滑条（太阳仰角 / 浊度 / 季节 R /
  地面高度），**右列** 4 个物理滑条（**胡克 h / 重力 g / ARAP b / 阻尼 u**）。
- **地面自动定位**：在 BuildSim 里、**Build 之前**按模型包围盒放下（模型底部下方
  0.5 个模型高度），滑条范围随之自适应。⚠️ 顺序很重要：`Build → Reset` 会做一次
  初始地面投射，若此刻 ground_y 还是默认值而模型更低，模型会**一上来就被压出畸变**
  （实测灯罩最低点 y ≈ −3.0 与默认 ground_y = −3.0 冲突，t=0 就有 5% 边长畸变 +
  7% 退化旋转）——那是纯人为初值错误，不是力学。
- **headless**：`--headless_drop` 逐帧推进并落盘 PNG；`--ui_shot` 单帧带面板自检。
  另有单变量对照实验开关（同样是 headless 批量跑用）：
  `--hooke/--gravity/--arap/--damping/--substeps`。

**两个诊断量的区别**：

| 量 | 含义 |
|---|---|
| `shape_residual_rms()` | ARAP 目标偏差（**局部形状**违反度）。局部形状保持时接近 0，**即使整体被压扁** |
| `edge_distortion_rms()` | 边长畸变 RMS（旋转/平移不变）→ 才是「被压扁了多少」 |
| `max_stable_dt()` | 显式积分稳定上限估计（Gershgorin 行和），见 §7.2 |

## 7. 🔑 关键实测结论（2026-09-23，全部为 headless 实测数据）

测例：内置方块（8 质点）／路灯 Lantern.glb（2737 质点）／抛石机 catapult.glb
（4481 质点，平均边长 ≈ 0.02）。默认四参数 h=300 / g=9.8 / b=300 / u=1，dt=0.05 s。

### 7.1 三个资产的实测行为

| 资产 | 质点数 | 落地后高度 / 原始 | 边长畸变 | 现象 |
|---|---|---|---|---|
| 内置方块 | 8 | 98% | 1%~3% | 落地弹几下，形状基本保持 |
| 路灯 | 2737 | 72%（下垂 28%） | 9%~25% | 站着，但明显变矮、灯笼下沉 |
| 抛石机 | 4481 | **5%（摊平）** | 6%~25% | 落地后 1~2 s 内**缓慢摊成一张饼** |

### 7.2 稳定性：`dt` 上限由**最短的边**决定

`k_e = h/L0` ⇒ **边越短弹簧越硬** ⇒ ω ∝ 1/√L0。因此同一个 h 下：

| 资产 | max_stable_dt | dt=0.05 需要 |
|---|---|---|
| 内置方块 | 0.045 s | 3 子步 |
| 路灯 | 0.0041 s | 25 子步 |
| 抛石机 | 0.0015 s | 68 子步（App 自动派生，封顶 64 时告警） |

App 每帧按当前 h/b 自动把 0.05 s 细分成子步（≤ 0.5·上限；`--substeps` 可强制）。
**注意：细分子步只改分辨率、不改力模型**，这是"步长不够"的正解，不是加因子。

### 7.3 抛石机「摊平」的根因：自重压垮，不是数值发散

单变量对照（其余参数不动）：

| 实验 | 结果 | 结论 |
|---|---|---|
| `g = 0`（关重力） | 5 s 内形状**完全不坏**（畸变 5e-4、形状力 1e-4） | 摊平 100% 由重力驱动，**不是积分不稳定** |
| `u = 1 → 20`（阻尼 ×20） | 落地（≈1 s）时形状完好（97%），随后仍**准静态地**缓慢压成饼（2~3 s） | **不是冲击/动能问题**，是静态自重压垮 |
| `g = 1.0`（重力 ÷10），5 s | 高度**一直保持 100%**（0.881 → 0.881） | **承重/刚度比**就是决定量 |
| `b = 300 → 3000`（ARAP ×10） | 仍然摊平（2 s 时高度 42%，与基线几乎一致） | ARAP 不承担这个荷载 —— 摊平走的是**近等距折叠**路径（ARAP 零代价），真正承重的是**边弹簧 h** |

**定量根因**：m = 1 是**逐质点**的，而刚度 k_e = h/L0 与质点数 N 无关。
一根长 L、由 n 段组成的竖直链在自重下的伸长 ≈ `m·g·L·n / (2h)`，即：

```
自重下垂 ∝ N · m · g · L / h        （N = 质点数）
```

| 资产 | N·m·g·L/h 量级 | 预测 | 实测 |
|---|---|---|---|
| 内置方块 | 8·9.8·0.9/300 ≈ 0.23 | 不塌 | 不塌 ✓ |
| 路灯 | 2737·9.8·25.7/300 ≈ 2300（3D 分摊后小得多） | 明显下垂 | 下垂 28% ✓ |
| 抛石机 | 4481·9.8·0.5/300 ≈ 73（远大于自身高度 0.88） | 必塌 | 摊平 ✓ |

⇒ **同一个物体网格越细 → 总质量越大 → 越会被自重压垮**。边长归一化只解决了
"刚度"这一半；**质量没有跟着归一化**，所以行为随网格分辨率漂移。
这与需求方"弹簧串联"的推理是同一个道理，只是要应用到惯性上：
**m 也要按"分了几块"归一化（m = 1/N 或按面积/体积加权），否则细网格相当于铅块。**

### 7.4 修法与代价（需要决策，见 §9）

| 方案 | 效果 | 代价 |
|---|---|---|
| **A. 质量归一化** m_i = 1/N（或经验面积加权） | 同一物体任意分辨率行为一致；抛石机自重下垂降到 ~0.008（远小于 0.88） | 稳定上限 ∝ √(m/k) ⇒ 抛石机要多 ~67 倍子步（≈4500 步/帧），显式积分 + 0.05 s 不现实 |
| **B. 只对粗网格用**（把参与仿真的网格减面到几百质点） | 保持现模型与 0.05 s 步长 | 需要一步"碰撞/仿真用粗网格"的前处理（Tripo 资产 4k+ 质点） |
| **C. 换数值方案**（隐式 / XPBD 合规约束） | 刚度与 dt 解耦，可同时"硬且快" | 不是本 PR 范围，是方案级改动 |
| **D. 什么都不改** | 那就要接受"细网格会摊平"是该参数组合（h=300, g=9.8, m=1）下的**正确**结果 | 与"衣物贴体"目标冲突：贴体要求结构能撑住自身重量 |

## 8. 物理参数（代码内默认 + 面板可调）

| 参数 | 默认 | 含义 |
|---|---|---|
| `hooke`（h） | 300 | 胡克系数；边刚度 `k_e = h/L0`（按初始边长归一化） |

| 步长 | 0.05 s（固定，需求方指定） | 半隐式欧拉 |

## 10. 已废弃：2026-09-22 的 PBD 方案（历史记录，勿参考）

首版实现的是**松弛式 PBD**（每子步投影：形状匹配 / 边长 / 弯曲 / 地面，另加切向摩擦、
整体平动摩擦、每秒恢复率量纲、迭代次数等），共有 **6+ 个可调量与若干补丁**。
需求方 2026-09-23 明确要求恢复为上面这套四参数最简模型，理由：**要先跑通最简单的模式，
塌陷就去定位问题根因，而不是继续加不确定因子**。上一版留下的三条结论**仍然成立**，
因为它们描述的是模型性质而非实现细节：

1. **ARAP 允许等距变形（弯曲/折叠）零代价** —— 它只抵抗拉伸压缩。所以薄板拼装结构
   （抛石机、灯罩、衣物）会沿"折叠"这条零能量路径走，这是 §7.3 里 `b ×10 也没用` 的原因。
2. **薄壳的 1-ring 近似共面 ⇒ 极分解退化**（灯罩玻璃、单层纸面、布料）。
   本版仍保留**法向增广项** `A += δ²·n_cur⊗n_rest`（对刚性运动有 `A = R·B`，
   B 对称正定 ⇒ `polar(A) = R`，**不破坏旋转不变性**，只把秩补满；
   单测 `ArapForceIsZeroUnderRigidRotationOfFlatMesh` 就是它的负向验证）。
3. **短边过滤**：真实资产有 1e-5 量级的退化短边，而 `k_e = h/L0` 让它们极硬 ⇒
   一步就能拉爆整个仿真。故拓扑保留、**弹簧力与畸变度量跳过**它们（跳过条数会打印）。

上一版还测得（数值细节，仅作参考）：PBD 的"每子步投影比例 s"等效刚度 `k ≈ s/h²`，
不是物理刚度；形状匹配放进迭代循环会让 softness 旋钮失效；`v=(x−prev)/h` 从位置投影
反推速度会在"约束互相打架"时泵能量（本版显式格式里速度是独立状态，自然没有这个坑）。
