# JPOV ARAP 软体查看器（arap_viewer）设计说明

> 状态：分支 `feature/20260922-jpov-arap-viewer`（本地提交，未 push）。
> 作者：James（2026-09-22 首版；2026-09-23 按需求方指示恢复为「四参数最简模型」）。
> 目标：把「衣物自动贴合人模」这条链路里**动力学仿真**那一环先落地成可交互验证的工具。

---

## 1. 目标与非目标

**目标**

1. 一个与 `jpov_model_viewer` **并列**的交互式查看器：能加载 glb、调视角/光照/地面高度。
2. 额外提供**软体动力学**：把网格当作可变形软体，在重力场里从高处摔到地面，观察形变。
3. 交代清楚「CPU 网格变形后，法线/切线怎么办」。
4. 物理模型**只有需求方指定的四个参数**（胡克 h / 重力 g / ARAP b / 阻尼 u），
   全部可在面板上实时调；界面另暴露光照与地面高度。

**非目标**

- 不接骨骼/蒙皮（那是 `jpov_clothes_rig_design.md` 的 weight transfer 一环）。
- 不做自碰撞（衣服 vs 衣服）、不做真实人体碰撞（地面是平面）。
- **不做 bending（弯曲刚度）**、不做体积保持、不做摩擦 —— 四参数模型里没有它们
  （2026-09-23 需求方指示：先把最简模型跑通，塌陷就定位问题根因，不要靠加因子掩盖）。

## 3. 力的模型（物理材质，2026-09-23 需求方定稿；MKS）

长度单位 = **米**（glb 的 cm 资产在加载边界已换算，见 §3.4）。质量**不是**逐质点 1 了 ——
**由面密度决定**。四个力：

```
① 胡克弹簧（每条边一根）：F = −k_e·(L − L0)·û ,  k_e = T / L0        T = hooke_n_per_m [N/m]
② 重力 mg
③ ARAP 局部形状力：F_i = β·(goal_i − x_i) ,  β 默认由 T 换算（β = T/7）
④ 线性阻尼：F_i = −u·m_i·v_i ,  u = damping_per_second [1/s]
```

积分：**显式（半隐式）欧拉**，固定步长 0.05 s（需求方指定）。地面 = 位置硬约束 + 法向速度归零。

### 3.1 质量由面密度给出（关键：与网格密度无关）

```
顶点面积 area_i = Σ_{t∈tris(i)} area(t)/3      （三角形给三个顶点各 1/3）
m_i = ρ · area_i                                ρ = area_density_kg_per_m2，默认 1 kg/m²
```

⇒ **同一块布无论三角化多细，总质量都一样**（细网格只是把同样的质量分给更多质点）。
这正是上一版踩到的根因：上一版刚度按边长归一化（k = h/L0）、**质量却按顶点数计**，
于是"细网格 = 铅块"——抛石机 4481 质点在自重下被压平（实测：g=0 时 5 s 不变形，
g=9.8 时摊成饼；b×10 也无效，因为压平走的是 ARAP 零代价的等距折叠）。
面密度把质量也纳入物理后，这个自由度就没了：想调"承重"就调 ρ 或 T，都是物理量。

### 3.2 两类刚度都用物理量给

| 参数 | 语义 | 默认 |
|---|---|---|
| `hooke_n_per_m` | 边弹簧：**T = 伸缩刚度**，k_e = T/L0 ⇒ 「0.1 m 的伸长产生 10 N 的力」 | 100 N/m |
| `arap_stiffness_n_per_m` | ARAP：β，0 = 按 `kArapPerHooke = 1/7` 从 T 换算 | 0（自动） |

`β = T/7` 的来历（写在 arap_sim.h）：ARAP 的单位位移恢复力约为 `(n̄+1)·β`，与边弹簧
"单位位移 → k_e" 对齐即可取 `β = T/(n̄+1)`；典型三角网格平均 1-ring 度 n̄ = 6 ⇒ T/7。
好处是**调 T 不会改变 ARAP 与胡克的相对硬度**（需求方要求"ARAP 跟着胡克换算"）。

### 3.3 阻尼按"每单位质量"给

`F = −u·m·v` ⇒ 加速度域是 `−u·v`，表现为「每个质点的速度衰减时间常数 1/u」，
**不随面密度与网格密度漂移**（若写成"每质点固定阻尼系数"，细分后阻尼就变味了）。

### 3.4 单位铁律：加载边界把资产换算成米（src/gltf_loader.cc）

仿真里 `面密度 / 胡克 / 重力` 都有量纲，单位不一致会直接换错材质。判据：

1. `asset.extras.unit` 显式标注 `"m"` / `"cm"` ⇒ 直接采信；
2. 顶点最大尺度 **≥ 10 m** ⇒ 判为 cm（现实里 10 m 以上资产极罕见；cm 资产当成米正好大 100 倍）；
3. 其余 ⇒ 原样透传（保证既有渲染行为不变）。

实测：`Lantern.glb` 顶点 25.66 ⇒ ×0.01 后是 0.257 m 的路灯（验证：该资产 gold 对比 diff
由 0 变为 49.3，说明换算确实生效且渲染仍正常）；抛石机 0.98 m、scene 资产（table/stool/
houseplant）本来就是米 ⇒ 透传。

⚠️ 两个**踩过的坑（判据写法）**：
- **不能用「100 的整数倍」**：25.66 / 100 = 0.2566 不是整数，但它是 2570 cm —— 被 100 整除
  是不必要条件（真实物体尺寸本来就不是整米数）。
- **不能用「有 node scale=100」判小资产为 cm**：实测 scene 资产顶点只有 2.8 / 0.58 / 0.38 cm
  且带 node scale=100，那是"顶点存 cm、scale 放大成 m"的典型做法，**它们本来就是米**；
  误判会让 scene gold 整体缩小 100 倍（开发中实测到过，靠 gold 图才发现）。

### 3.5 稳定性（显式积分）：诚实报错，不靠加力掩盖

`max_stable_dt()`（Gershgorin 行和，已计入质量）：
`row_i = Σ_边 k_e/m_i + β·n_i/((n_i+1)·m_i)`，返回 `2/√max row`。

新增 `AnalyzeMasses()`：**不建仿真器**就能算出总面积/总质量/最大 `k_e/m`，于是 BuildSim
在 Build 之前就打印「面密度诊断 + 稳定步长先验 + 四种不改力模型的解决办法」，
而不是让用户看着模型飞走。实测（ρ=1 kg/m²、T=100 N/m）：

| 资产 | 质点数 | max_stable_dt | 步长 0.05 s |
|---|---|---|---|
| 内置方块 | 8 | 0.071 s | ✅ 子步 2 |
| 路灯 | 2737 | 5.7e-5 s | ❌ 需 1748 子步（封顶 64） |
| 抛石机 | 4481 | 1.5e-6 s | ❌ 需 66465 子步 |

⇒ 高模资产在物理刚度下**必须减面/放宽网格，或换隐式积分**。这不是调参能绕的，
是"资产粒度 + 显式积分 + 物理刚度"三者共同决定的事实。

## 4. 拓扑：物理用「焊接」，渲染用「不焊接」

| 用途 | 拓扑 | 为什么 |
|---|---|---|
| **物理**（弹簧/ARAP/地面） | **按位置焊接**（ε = 1e-6，仅在 bind pose 判定一次） | UV 缝两侧的顶点几何上是同一表面点；不焊接会被弹簧力拉开成**裂缝** |
| **渲染**（法线/切线） | **不焊接**（按顶点索引取邻域） | 顶点分裂是数据的一部分：硬边靠它保留（反例：直棱柱三条棱交会处一个位置三个顶点，法线分别是上/左/右面） |

**多 primitive = 同一个物理物体**：焊接跨 primitive 进行（资产常按材质切开，
如 lantern.glb = 杆/链/灯罩），接缝处位置重合的顶点焊成同一质点 ⇒ 各部件互相支撑；
若各自独立仿真，各部件互不支撑、看起来像模型散架（2026-09-22 实测）。

## 5. 变形后法线/切线怎么办

**不"补"，也不"旋转旧值"——每帧用变形后的位置重跑同一个函数。**

```
Step() → WriteBackPositions() → RecomputeTangentSpace() → UpdateMesh() → Draw()
```

- **法线**：面叉乘 → 面积加权累加到顶点 → 归一化（按**索引**，不焊接）。
- **切线**：`T = ∂P/∂u`，用变形后位置 + 不变 UV 解 2×2 方程，公式与
  `obj_loader.cc` / `gltf_loader.cc` 逐字一致（同源，不产生第二套约定）。
- **B 不存**（shader 内 `cross(N,T)`）；**法线贴图无需处理**（切线空间相对方向 + UV 不变）。

## 6. 相机、UI 与 headless

- **取景**：球面角相机目标点下移到「模型顶 ↔ 地面」中点，按所需垂直半跨度反推 R。
- **UI**：顶部 2 按钮（动力学启停 / 重置 mesh）+ 状态文本（质点数 / 边长畸变 / 形状力 /
  退化旋转 / 子步数）；底部**左列** 4 个光照·标高滑条（太阳仰角 / 浊度 / 季节 R /
  地面高度），**右列** 4 个物理滑条（**胡克 h / 重力 g / ARAP b / 阻尼 u**）。
- **地面自动定位**：在 BuildSim 里、**Build 之前**按模型包围盒放下（模型底部下方
  0.5 个模型高度），滑条范围随之自适应。⚠️ 顺序很重要：`Build → Reset` 会做一次
  初始地面投射，若此刻 ground_y 还是默认值而模型更低，模型会**一上来就被压出畸变**
  （实测灯罩最低点 y ≈ −3.0 与默认 ground_y = −3.0 冲突，t=0 就有 5% 边长畸变 +
  7% 退化旋转）——那是纯人为初值错误，不是力学。
- **headless**：`--headless_drop` 逐帧推进并落盘 PNG；`--ui_shot` 单帧带面板自检。
  另有单变量对照实验开关（同样是 headless 批量跑用）：
  `--hooke/--gravity/--arap/--damping/--substeps`。

**两个诊断量的区别**：

| 量 | 含义 |
|---|---|
| `shape_residual_rms()` | ARAP 目标偏差（**局部形状**违反度）。局部形状保持时接近 0，**即使整体被压扁** |
| `edge_distortion_rms()` | 边长畸变 RMS（旋转/平移不变）→ 才是「被压扁了多少」 |
| `max_stable_dt()` | 显式积分稳定上限估计（Gershgorin 行和），见 §7.2 |

## 7. 🔑 关键实测结论（2026-09-23，全部为 headless 实测数据）

### 7.1 上一版（逐质点 m=1）暴露的根因：`质量没跟着归一化`

上一版只有无量纲的 h/g/b/u，m 逐质点 = 1。实测三资产（h=300, g=9.8, b=300, u=1）：

| 资产 | 质点数 | 落地后高度 / 原始 | 边长畸变 | 现象 |
|---|---|---|---|---|
| 内置方块 | 8 | 98% | 1~3% | 弹几下，形状基本保持 |
| 路灯 | 2737 | 72% | 9~25% | 站着但明显变矮 |
| 抛石机 | 4481（边长 0.02） | **5%（摊平）** | 6~25% | 落地后 1~2 s 缓慢摊成一张饼 |

单变量对照（抛石机，其余不动）：

| 改一个量 | 结果 | 说明 |
|---|---|---|
| `g = 0` | 5 s 内形状**完全不坏**（畸变 5e-4） | 摊平 100% 由重力驱动，不是数值不稳定 |
| `u: 1 → 20` | 落地时完好 97%，之后仍准静态压扁 | 不是冲击/动能，是静态自重压垮 |
| `g ÷ 10` | 高度**一直保持 100%** | 决定量是"自重/刚度"比 |
| `b × 10` | 几乎无效（仍摊平） | 压平走 ARAP 零代价的**等距折叠**，承重的是边弹簧 |

**根因**：m 逐质点 = 1，而刚度 k = h/L0 与质点数无关 ⇒ 自重下垂 ∝ N·g·L/h
（抛石机 ≈ 73 ≫ 自身高度 0.88）。**"刚度按边长归一化"只做了一半，质量也得归一化** ——
这就是本轮引入面密度（§3.1）的原因。

### 7.2 本轮（物理材质）后的量级

默认 ρ = 1 kg/m²、T = 100 N/m、β = T/7、g = 1.0（面板默认）：

| 资产 | 总面积 | 总质量 | max_stable_dt | 现实尺寸 |
|---|---|---|---|---|
| 内置方块 | 4.86 m² | 4.86 kg | 0.071 s（步长内） | 0.9 m 立方 |
| 路灯 | 434.9 m² | 434.9 kg | 5.7e-5 s | **0.257 m 高**（cm 资产换算后） |
| 抛石机 | 2.38 m² | 2.38 kg | 1.5e-6 s | 0.98 m 高 |

方块（唯一落在稳定步长内的资产）实测：落地后边长畸变 1%、高度保 99%，行为正常。

**注意路灯换算后的物理尺寸只有 0.257 m** —— 面板/相机都按米取景，故看起来偏小；
这是"资产本来就这么大"的正确呈现（对照：该资产 gold 渲染的判据与换算前一致通过）。

## 10. 已废弃：2026-09-22 的 PBD 方案（历史记录，勿参考）

首版实现的是**松弛式 PBD**（每子步投影：形状匹配 / 边长 / 弯曲 / 地面，另加切向摩擦、
整体平动摩擦、每秒恢复率量纲、迭代次数等），共有 **6+ 个可调量与若干补丁**。
需求方 2026-09-23 明确要求恢复为上面这套四参数最简模型，理由：**要先跑通最简单的模式，
塌陷就去定位问题根因，而不是继续加不确定因子**。上一版留下的三条结论**仍然成立**，
因为它们描述的是模型性质而非实现细节：

1. **ARAP 允许等距变形（弯曲/折叠）零代价** —— 它只抵抗拉伸压缩。所以薄板拼装结构
   （抛石机、灯罩、衣物）会沿"折叠"这条零能量路径走，这是 §7.3 里 `b ×10 也没用` 的原因。
2. **薄壳的 1-ring 近似共面 ⇒ 极分解退化**（灯罩玻璃、单层纸面、布料）。
   本版仍保留**法向增广项** `A += δ²·n_cur⊗n_rest`（对刚性运动有 `A = R·B`，
   B 对称正定 ⇒ `polar(A) = R`，**不破坏旋转不变性**，只把秩补满；
   单测 `ArapForceIsZeroUnderRigidRotationOfFlatMesh` 就是它的负向验证）。
3. **短边过滤**：真实资产有 1e-5 量级的退化短边，而 `k_e = h/L0` 让它们极硬 ⇒
   一步就能拉爆整个仿真。故拓扑保留、**弹簧力与畸变度量跳过**它们（跳过条数会打印）。

上一版还测得（数值细节，仅作参考）：PBD 的"每子步投影比例 s"等效刚度 `k ≈ s/h²`，
不是物理刚度；形状匹配放进迭代循环会让 softness 旋钮失效；`v=(x−prev)/h` 从位置投影
反推速度会在"约束互相打架"时泵能量（本版显式格式里速度是独立状态，自然没有这个坑）。
