# 海谱选型场（Ocean Lab，场景 4）

2026-11-20，Danis：「把它们合到一个 viewer 里选型…… 场景下做个 ABC 三分类，
把动态的海做进去，可调的滑条帮我颜色上整一个，海底底板来一张」。

## 跑法

```
output/jpov_skylight_viewer/jpov_skylight_viewer --ocean-lab
```

- 直接进「场景 4 海谱选型」，面板已在底部；也可在交互窗口里
  `场景` 下拉 → `场景4 海谱选型（ABC）`。
- 默认 = 预实验的拍摄参数：太阳 35°/214°、σa 0.50/0.054/0.014、σs 0.04、
  风速 8 m/s、曝光 0.6、机位 45° 俯视 / 相机高 5 m / 朝太阳。
- 波浪默认**动态**（真实时钟）。想看静止的对齐帧：勾「波浪 冻结时间」再拖「波浪 时间 s」。

headless 存档（A/B/C × 3 机位，时间冻结在 7 s）：

```
jpov_skylight_viewer --capture-ocean-lab    <out_dir>
jpov_skylight_viewer --capture-ocean-lab-ui <out_dir>   # 连面板一起拍，验收 UI 布局
```

## 三份谱（`demo/ocean_spectra.h`，由预实验 cfg 生成）

| | 结构 | 说明 |
|---|---|---|
| **A** | 8 主波 + 48 细节（55° 扇面，Phillips 式对数波长） | 最有"涌"的方向性；近景偏规则、40 m 处读成交叉网 |
| **B** | 4 主波 + 64 细节（方向均匀、等陡度） | 最各向同性、最不 period；缺方向性 |
| **C** | B + 域扭曲 warp（载波 120/210/360/610 m、幅度 6 m，**按波限带**） | B 的通透 + 大尺度弯曲 |

warp 限带（`kWarpSlopeLimit = 0.25`）见 `src/water/water_wave_math.h::WaveWarpSlopeBound`：
旧参数（16 m / 37–197 m 载波）k·U ≈ 4 ⇒ 34 m 主波的有效波长在 −75…+147 m 之间扫
（波峰折叠成漩涡）+ 短波相位被打散成拉丝。限带后主波 k·U ≤ 0.12、1 m 级细节 k·U ≥ 1
（自动几乎不吃位移）。

## 面板（14 行 × 2 列）

左列：场景 / 海谱 A·B·C / 主波波幅倍率 / 细节短波倍率 / warp 幅度 m /
时间速度 / 风速 / 吸收 R·G·B / 散射 / 曝光 / 海底深度 / 海底反照率
右列：天体仰角 / 方位角 / 浊度 / 水皮 / 水体介质 / 真位移 / 海底底板 / 冻结时间 / 时间 s

- **颜色**：物理口径是逐通道吸收（R 吸收越强越蓝），"吸收 R"就是那个水色旋钮；
  想更绿把它拉低、想更蓝拉高，配合 `散射` 控制浑浊。
- **浅海**：海底 = 12×12 块 16.7 m 的棋盘格沙底（两档反照率 1.0/0.74）。
  为什么不用纯色：3 m 深、45° 视线时沙底要穿过约 8.5 m 水 ⇒ 红通道只剩 ~1.5%，
  单一沙色被染得和水体一样青，"看不见底"；棋盘格是唯一低成本能读出底的结构，
  而且越深越淡 —— 正好是浅海的读法。滑「海底深度」可以直接看深浅过渡。

## 已知项

- 掠射（10°）时远处仍有沿视线的摩尔纹：像素足迹是各向同性标量且带 0.15 地板
  （known_issue §10.13），与本场景无关，改它会动所有出图。
- 场景 4 只画海底，不画方块/人：选型要比的是谱，不希望物体倒影干扰。
