# 水体 / 水皮 / 天球折射 —— 契约（2026-11-16 Danis 定稿）

> 本文只写**职责边界与口径**，不写实现教程。已知缺陷见 `tools/jpov/known_issue.md` §10 / §11。
> 目的：把"水体这块到底谁负责什么"压缩成三条可背诵的判据，不再每次重新推导。

---

## 0. 一页总图

```
                    ┌──────────────── 合成器（TransparentComposite）────────────────┐
点状雾 ──froxel──┐   │  只认「场」和「层」，不知道介质种类                            │
                 ├──→│  段 ↔ 层 交替：L += W·(S_i−S_prev)；L += W·e^{−τ_i}·C_i；W *= T_i │
解析水体 ─At()───┘   │  out = L + W·e^{−(τ_op−τ_prev)}·bg                          │
                    └───────────────────────────▲───────────────────────────────────┘
                                                │ 层（C, T, z̄）
                                         水皮（界面，WBO）
```

三条判据：

1. **需要 z 吗？** 需要 → **层**；不需要 → **场**。
2. **有位置 / 有厚度 / 需要和不透明深度比较** → 层；**沿视线连续累积** → 场。
3. **层只能做两件事**：加一份色 `C`、把背景乘一个标量 `T`。**任何"把背景换成另一个方向的内容"都不是层。**

## 1. 水体 = 场（`fog_water` 装置）

### 1.1 接口（唯一）

```glsl
void MediumAt(vec3 ro, vec3 rd, float z, out vec3 tau, out vec3 S)
```

- 语义：**从相机到 z 的前缀累积**（任意区间 = 两次前缀相减）。
- `S` 必须是**相机参考**的（内部 `B = 1 − dy_w/toward.y` 里的 `1` 就是视线衰减）——这是合成器用差分而不乘 T 的前提，改不得。
- 实现：froxel 雾场 + 解析水体，两者在 `FieldAt` 里**相加**。

### 1.2 直线积分 + 折射能量

| 维度 | 口径 |
|---|---|
| 参数化 | **视线本身（直线）**。它只决定几何：入水点 `P`、终点深度（`z_op` / 层 `z̄`）、排序 |
| 积分变量 | 物理斜程 `s`；`ds/dt = cosθa / cosθw`（`len_w = len·|rd.y|/|dy_w|`） |
| 源函数 `J` | **按折射后的光场算**：太阳方向折射、界面 `(1−R)`、`cosθa/cosθw`、HG 相位、天光 `n²` |

**为什么这是精确的**：水体水平均匀 ⇒ 直线与折线经过同一组深度，`J` 与剩余衰减都只依赖深度，测度换算正好等于 `dτ/dt` ⇒ 换元前后积分值相同。**唯一的损失是成像位置**（哪条线上的哪个物体），那是明确不管的。

**前提（写死）**：这条精确性依赖**水平均匀**。水体形状化（体素/任意形状）后必须改成沿折射路径 DDA —— 见 `known_issue.md` §11.5。

### 1.3 雾只在水上（约束，不是假设）

`τ = τ_fog + τ_water` 只在两个介质**互不衰减对方**时精确。正确式子是
`∫ e^{−(τf+τw)}(j_f + j_w)`，无闭式。

处理方式：**约定雾场的定义域在水面以上**（`Build` 时发现水下密度就 `CHECK`）。
这样两者空间不相交 ⇒ 交叉项恒为 0 ⇒ 相加精确。

> 通用规律：解析介质与离散介质共存时，交叉衰减无闭式；让离散方承担（它有 slice），或让两者空间不相交。

## 2. 界面 = 层（水皮）

### 2.1 层契约

| 字段 | 含义 | 硬要求 |
|---|---|---|
| `C` | **P 点的出射辐射度，未经相机段衰减** | 相机段的 `exp(−τ)` 由合成器施加 |
| `T` | 层自身的透射率（标量，逐像素） | `T ≤ 1` |
| `z̄` | 水面交点的**射线距离**（`t`，欧氏） | **不是视轴深度**（`t·dot(rd,fwd)`）；后者会让层被放早 `1/cosθ`（角落 ~1.5×） |
| `α` | 即 `1−T`，**没有物理含义约束** | 别真的写 0：`accum.a ≤ 1e-8` 会被 `ResolveLayer` 丢掉 |

### 2.2 水下（相机在水下看水面）

| 区域 | `α` | `C` |
|---|---|---|
| Snell 外（TIR） | **1** | `S_P(∞)` —— P→∞ 的深海解析积分 |
| Snell 内 | `F`（0.02~0.1，接近透明） | `F·S_P(∞)`（同一个式子） |

- 临界角：**法线 48.6066° / 仰角 41.3934°**（从水平量）。
- `S_P(∞)` = `MediumAt(P, mirror(rd), ∞)`：**同一个函数、不同起点与方向**，不是第二个积分器。
  以后接 SSR 只是把上限换成命中距离：`S(L) + T(L)·L_obj`，`L→∞` 即今天的 fallback。
- 窗内的天空压缩 / `n²` **不在这层**（见 §3）。
- 窗内的注入项 = `(1−F)·n²·L_sky(refract)`，但这条**不写进层**（层只透过背景）——见 §3 的取舍。

### 2.3 水上（相机在水上看水面）

| 项 | 定稿 |
|---|---|
| 反射 | `C = F·L_refl`，`L_refl = A·SSR(mirror) + (1−A)·sky(mirror)`（**加权混合，不是相加**） |
| 透射 | `T = (1−F)/n²` —— **`÷n²` 必须做**，否则水下内容偏亮 1.78× |
| ambient / diffuse | **恒 0**（纯界面、无泡沫、无次表面） |
| roughness | **无**（`LOD0`、无 lobe）⇒ 纯镜面，材质参数不需要任何新增 |
| 平行光高光 / 太阳的像 | **不做**（平面下是 δ 函数；需要波的法线分布，见 `known_issue.md` §10.3 / §10.10） |

接 SSR 时三个易错点：

1. `A·SSR + (1−A)·sky`，写成 `SSR + sky` 会双计（反射亮一倍）。
2. 地平线夹取（1°）**只作用于探针支路**；SSR 命中是真实几何，夹了会把岛/树压平成一条线。
3. `sky_scale` 单一出处（水皮 `env_scale` == SSR `env_sky_scale`），否则开关 SSR 会顺带改变反射总量。

### 2.4 为什么 `÷n²` 能进层、`×n²` 不能

`T` 是标量透射率，只能 **衰减**背景：

- 水上→看水下：需要 `÷1.777`（`T=(1−F)/n²`，正入射 `T=0.551`）⇒ **能**表达；
- 水下→看水上：需要 `×1.777`（`T>1`）⇒ **不能**表达 ⇒ 只能靠天空装置重定向（§3）。

这条不对称是"水下要靠天空自我折射、水上不用"的全部原因。

## 3. 天球折射 = 天空 pass 的**后处理**（不进入天空逻辑）

### 3.1 硬约束：写成独立的方向变换

```glsl
// 唯一入口：在 Preetham 求值 / 日盘判定之前
void WaterBendDir(vec3 raw_dir, out vec3 dir, out float gain)
```

- 相机在水上、或射线不穿过水面（`t = (level−camY)/rd.y ≤ 0`）⇒ `dir = raw_dir, gain = 1`，**逐字节零回归**。
- 否则：`dir = refract(raw_dir)`，`gain = n²`（1.777）。
- **禁止**写成 `if (underwater) 走另一条天空分支` —— 那是把水耦合进天空逻辑。
- 地色填充、光晕、地平线处理、日盘形状 **一行都不改**。

### 3.2 两趟必须一致

`kFull`（主色）与 `kAtmoOnly`（远景雾的收敛色，`HorizonFogRenderer` 按同像素 uv 采样）都要调用同一个 `WaterBendDir`。只弯主色不弯 `kAtmoOnly` ⇒ 窗内远景雾会朝未折射的天色收敛，出现一层雾色偏差。

### 3.3 探针 cube **不弯**

`kEnvProbe` 是**方向函数**，没有"相机在水下"这件事。后果（接受）：水下物体的镜面 IBL 仍用空气侧天空（缺 `n²`、缺 Snell 锥限制、缺 `(1−F)`）—— 物体侧缺口，另记。

### 3.4 环边 padding

- 采样方向的**仰角钳到 3°**（气侧，可调 2~5°）；同方位角。
- 依据：气侧 0~3° ↔ 水侧 41.4°~43.0°（最外 1.6°），压缩比 ~17× ⇒ 亚像素级，几乎不可见，但正好盖住天空模型的地平线奇点。
- **钳方向，不是钳颜色**：C0 连续，且保留方位依赖（太阳侧白天顶侧暗）。

### 3.5 收益（为什么值得动天空 pass）

1. **太阳的位置**：气侧仰角 < 41.4° 的太阳今天在水下**完全不可见**（画在 TIR 区被 α=1 盖掉），本该被抬到窗内（30° → 49.5°）。
2. **天空压缩 + 环边地平线亮带**：环边压缩比 ~20×，是"一眼认出是不是水窗"的判据。
3. **`×n²`**：窗内亮度。

代价只有"水上物体位置不跟着压"——表现为"物体相对平滑天空的位置偏了"，深海 + 远景场景下几乎为零；接几何折射（gather）后自动收敛，**不需要回退这一项**。

## 4. 合成顺序（唯一决定顺序的地方）

```glsl
L = 0; W = 1; tau_prev = 0; S_prev = 0;
for (层 i, 按 z̄ 升序) {
    zi = min(z̄_i, z_op);
    (tau_i, S_i) = FieldAt(zi);
    L += W * (S_i - S_prev);          // 段注入（前缀差分，相机参考）
    L += W * exp(-tau_i) * C_i;       // 层色（被前面那段水衰减）
    W *= T_i;                         // 层自己的透射
}
(tau_op, S_op) = FieldAt(z_op);
L += W * (S_op - S_prev);
T = W * exp(-(tau_op - tau_prev));

out = L + T · bg
```

- 逐通道 `T` ⇒ 固定管线做不了 `dst·T + L`，**两次 draw**（`ZERO/SRC_COLOR` 乘 T；`ONE/ONE` 加 L；加 L 那趟 alpha 必须写 0）。
- 实现备注：合成趟的触发条件必须包含 `water_present`（不仅是 `run_fog || water_medium_on`），否则"只开水皮不开水体介质"时层没人消费。

## 5. 光学口径（三条规则，贴墙）

| 消费的是 | 过界面要乘 |
|---|---|
| 辐照度 `E`（点光照、注入源） | `(1−R)` |
| 辐射度 `L`（窗内天空、环里的反射） | `n²`（水→空气则 `÷n²`） |
| 法向辐照度 `E⊥`（太阳注入） | `(1−R)·cosθa/cosθw` |

三个 cos 别串：`cosθa` / `cosθw` 是**视线**的（进 `ds/dt`）；`toward.y` 是**太阳**的水内角（进 `exp(−σt·d/toward.y)`、`B`）。

## 6. 明确不做

| 项 | 理由 |
|---|---|
| 沿折射折线积分 | 需要 gather；直线 + 长度换算在水平均匀介质下是精确的 |
| 水皮替换/重定向背景 | 层表达能力之外（`T ≤ 1` 且只有一个标量） |
| 水体形状化 | 会让闭式作废（§11.5）；做时换 `At()` 的实现，不换槽位 |
| 介质消费 CSM | 会把闭式变成分段积分，且水下 CSM 口径本身待修（§11.1） |
| 水上物体的折射位移 | 屏幕空间 march 已否决（`7ab29a9`） |
| 太阳的像 / 平行光高光 | 需要波的法线分布；平面下是 δ 函数 |
| 水下多次散射 | 环里本质是多次散射，现在用"单次散射 + 各向同性 ambient"顶替（§11.2） |
