## 0. 宗旨

> **先保证不闪烁；再通过增加采样 或 TAA 提升光照正确性。**

不闪烁是**硬约束**（无 TAA 也必须成立）；正确性是**可调旋钮**。

## 2. 核心技术结论（讨论沉淀）

### 2.1 L_in 的形式与拆分

- `L_in` 是 **`Vec3`（RGB 内散射亮度）**，不是标量。
- **按频率拆两层**：
  - **慢变项**（ambient + 近邻点光）→ **每团预烘一个 `Vec3`**；点光源按团心 `linear_radius` cull（`B×L → B×平均灯数`）。
  - **sum × shadow（高频）→ 必须逐像素**（团心烘 shadow 出不了光柱）。

### 2.2 体积积分（单次散射）

```
S = ∫_{T0}^{T1} σ(t)·L_in(t)·exp(−τ_cam(t)) dt
L = L_scene · exp(−τ_total) + S
```

- **不计"介质对光的自遮挡"**（光学薄的单次散射近似）。
- **τ 全部闭式**（距离平方多项式剖面，如 `kDome`）；**唯一破坏闭式的是 `L_in(t)` 的 t 依赖**。

### 2.3 为什么不用 froxel

- 成本 `O(Nfroxel·(S+L) + Nfroxel·B + P·Z)`，**细/薄特征是死穴**：
  - 10cm@5m ≈ 20px ⇒ 要 `Nxy ≈ 105` 行才够 2 个体素；
  - 指数切片要在 5m 处达 10cm ⇒ `Nz ≈ 300~500`。
- **froxel 网格是"相机相对"的** ⇒ 有**格量化闪**，生产靠「抖动 + TAA」治 ⇒ **强依赖 TAA**，与"无 TAA 要能用"冲突。

### 2.4 逐像素闭式的定位

- **无网格、无格量化** ⇒ 配 VSM 后 **无 TAA 也不闪**。
- 关键在于 **连续性**，而不是"采样点选得对不对"（偏差 ≠ 闪烁）。

## 3. 第一组：不闪烁基础

| # | 组件 | 说明 |
|---|---|---|
| 1 | **闭合点雾，保连续 `t*`** | 球求交闭式 + 分段闭式 τ；剖面 `kDome`；采样点用**连续函数**（几何中心 / 权重质心） |
| 2 | **VSM 软化阴影边缘** | CSM 原地 `.g = d²`（AGBA32F 已有空闲通道，+1 行、+0 显存）→ **雾专用**高斯矩 buffer → Chebyshev。**物体影子仍走 PCF，主阴影不动** |
| 3 | **texel snapping 升级当前 CSM** | 级联正交盒世界平移到纹素整数倍 → 网格世界对齐 → 治 shimmer |
| 4 | **雾体列表稳定** | tile cap 取舍；当前判断"K=16 不易跳变"（**见 §6-风险 4**） |

**判定**：只要「像素弦积分的**采样点随几何连续不突变**」（如**有效遮挡段按遮挡比重分 4 份**布点），单像素积分结果即 **不闪烁**。

---

## 4. 第二组：屏幕空间深度敏感高斯（bilateral）

- 做法：**雾的最终遮挡色纹理 + 主视角深度图** → **深度敏感高斯**（cross-bilateral，range weight 用中心 depth 近似以保可分离）。
- 目的：治**屏幕空间的跳变 / 锯齿**。
- **局限**：**没法像 froxel 那样交叉关联纵深**（单层屏幕空间 = 2.5D 近似）。
- **见 §6-风险 5**（需先指明目标 artifact，且会软化细柱）。

---

## 5. 性能旋钮（后话）

- **增加 M** → 逼近完美（**注意与 VSM 糊宽的耦合，见 §6-风险 1**）。
- **或 M 不变 + TAA + 纵深采样抖动** → 大幅提升（**破坏确定性**，与"无 TAA 金标准"并存：见 §6-风险 6）。

## 6. 补充与风险（评审）

### 🧷 不闪烁保证清单

**连续性四条件**：
1. 采样位置 `t*` 是相机/视线的**连续函数**；
2. 阴影采样值连续（VSM 平滑）；
3. 查的是**世界对齐**的阴影（网格不滑）；
4. **雾体列表稳定**（不因别名跳）。

**五个会破坏连续性的坑**：
1. **采样点不连续**：用「被裁剪弦的中点」→ 遮挡一变就跳 ⇒ **改用几何中心 / 权重质心**。
2. **CSM 级联边界**：跨级联时 VSM 值跳 ⇒ **级联混合带**。
3. **级联盒未世界对齐** ⇒ **texel snap**。
4. **VSM 滤波宽 < 采样点移动尺度** ⇒ 残余闪 ⇒ 糊宽匹配段 footprint。
5. **tile cap 取舍**：blob 挤进/挤出 `≤K` 列表 → 贡献凭空出现/消失 ⇒ blob 在屏幕上出现"缝"。

### 🔴 风险 1（最重要）：VSM 糊宽 与 M 是**耦合旋钮**

- VSM 滤波宽须匹配**采样段足迹**，段长 = f(弦长, M)。
- **固定糊很宽 ⇒ 加大 M 也锐不起来**（"增加 M 逼近完美"失效）。
- ⇒ **用 footprint 自适应 mip 选级**（按段/屏幕导数），而非固定糊宽。
- 附带：**各级联 texel 世界尺寸不同 ⇒ 同宽糊的 penumbra 世界宽度不同 ⇒ 级联边界 penumbra 跳** ⇒ 逐级联补偿糊宽 或 级联 blend 带。

### 🔴 风险 2：分段必须在**未裁剪的球弦**上分

- 若在被场景深度裁剪后的区间上重新分 M 份 ⇒ 遮挡边界一动 4 点整体跳 ⇒ **反而闪**。
- ⇒ **在球弦（稳定域）上按不透明度分段；深度裁剪只改最后一段长度**。

### 🔴 风险 3：级联边界需要 **blend 带**（texel snap 不够）

- 采样点跨级联退时，深度映射 / 分辨率 / 糊宽都变 ⇒ VSM 值跳 ⇒ 闪。

### 🔴 风险 4：tile cap 触顶 —— 最弱环

- 目标"至多 1000 团"；**密集重叠时 cap 必然触顶** ⇒ 被丢/进的团贡献跳。
- "重要性排序"只**减小**跳幅，**消不掉**。
- ⇒ ① **埋点统计 cap 触顶率**；② 触顶则**提高 K / 预合并重合团 / tile 成员滞后（进易出难）**。

### 🟡 风险 5：第二组 bilateral 先定位目标，且会软化细柱

- 先**指明它治的具体 artifact**（VSM 低分辨率走样？tile cap 的缝？blob 轮廓？）。
- 若是 tile cap 的缝 ⇒ bilateral **修不了**（缺一块，空间传播补不回）。
- **会软化细柱、与第一组目标相冲** ⇒ **半径要小 + 做成可选开关**。

### 🟢 提醒 6：测试契约（白捡）

- **无 TAA 路径 = 确定 = 金标准**；将来 TAA 必须"静止收敛后 ≈ 它"（容差内）。
- 一份测试同时锁两条路，防 TAA 把画面带偏。

### 🟢 提醒 7：VSM 的 depth 可能为负

- 存的 depth 是"相对主视锥中心的米"，**可能为负**（物体在中心前）。`d²` 仍正；Chebyshev 里 `d=t−μ` 按符号分情况。RGBA32F 精度足够。
