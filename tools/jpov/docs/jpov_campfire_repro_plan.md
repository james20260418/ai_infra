## 0. 目标

用**拿来主义**逼近一个 CC0 篝火参考：以 **EmberGen 官方渲染**为标准答案，
把 JPOV 的体积火渲染（资产 + 后端 + 附件层）**逐条补齐机制**，直到渲染观感
**不弱于**官方；最终**在本地自烘一份等价 VDB 资产**（含 density/heat/flame 通道），
走同一套 A/B 达标。

方法论照搬「Tripo 模型渲染还原」：**先钉死标准答案 → 固定相机/帧 → 逐机制 A/B →
一律用像素量化验收**（不靠肉眼/vision 措辞——历史教训：vision 判读多次自相矛盾）。

## 1. 标准答案（Ground Truth）

**EmberGen 官方渲染**：`smallCampfire.mp4`（200 帧，1626×1152，纯黑底、孤立火 + 烟柱）。

- 来源：JangaFX EmberGen **免费 VDB（CC0，可商用）**
  `https://jangafx.com/software/embergen/download/free-vdb-animations`
  该套件自带 `.mp4` 官方预览渲染 + `.ember` 工程 + 200 帧 `.vdb` 序列。
- 它与我们手上的 CC0 VDB 是**同一份资产**，因此是「同一份 VDB 的官方标准渲染」——
  正适合做机器可比对的标准答案。

### 1.1 帧对应关系

| 环节 | 帧域 | 说明 |
|---|---|---|
| 官方 mp4 | `n ∈ [0, 200)` | 与 VDB 序列一一对应 |
| 源 VDB 序列 | `smallCampfire_%04d.vdb`，200 帧 | `n` 同上 |
| 我们入库的 `campfire.jpovvol` | `k ∈ [0, 80)` | 由**源帧 60..139**转换（`--start 60 --end 140 --ds 2`）|

⇒ **资产帧 `k` ↔ 官方帧 `60 + k`**。例：资产帧 0 ↔ 官方帧 60。

> ⚠️ 待 P1 核对：mp4 帧号与 VDB 帧号是否严格同序（EmberGen 导出默认同序；先用
> 端到端形状对齐确认一次）。

### 1.2 目标锚点（非 CC0，仅作"要像什么"）

`/james_pm/目标火焰.png`（520×497，123RF 水印）：照片级真篝火，含柴堆、余烬辉光、
被火照亮的地面、白热芯→黄→橙的色阶。这是**最终野心**（决定附件层 C 的验收），
**不作为像素比对基准**。

## 2. 机制清单（逐条可验证）

分三层。**A 层是"还原"的地基**（缺了它后端再调也白搭）。

### A. 资产 / 数据层

| # | 机制 | 现状 | 判定依据 |
|---|---|---|---|
| **A1** | **多场通道** | EmberGen campfire = 两个 grid：`flames`(火/反应，稀疏丝状) + `density`(烟，致密)。我们现在转换时 `--r-grid flames --g-grid flames` → **只带了 flames，烟整条丢失**，且 G 不是温度 | 参考图有**粗烟柱**，我们几乎没有 |
| **A2** | **温度场** | EmberGen VDB 无 temperature grid；官方"白心→黄→橙"来自它自家燃烧着色 | 我们的色阶偏黄白、无橙红层次 |
| **A3** | **分辨率 / 边界 / 尺度** | 下采样到 56×61×53；无边界淡出（硬盒边）；盒比例未按资产实际维数 | 盒边可见；细节糊 |

### B. 渲染后端层（raymarch）

| # | 机制 | 现状 |
|---|---|---|
| **B1** | 传递函数标定（黑体色温 + 发射曲线 + exposure） | 固定 `Tmax=2600`，G=flames，色阶未拟合 |
| **B2** | 烟：消光 + 受光（环境/单次散射） | 只有自发光，烟要么黑要么没有 |
| **B3** | 采样质量（步数 / 分层抖动 / 蓝噪声 / 时间累积） | 64 步仍见块感/banding |
| **B4** | 性能（低分金字塔 + 预算） | 全分辨率 |
| **B5** | 合成（TAB 多薄层 → MBOIT；代表深度接 froxel） | 单薄层 |
| **B6** | 时间稳定（去闪烁） | 未做 |

### C. 场景附件层（对应 §1.2 照片级靶子）

| # | 机制 |
|---|---|
| C1 | 点光（火照亮柴堆 / 地面） |
| C2 | bloom / 辉光 |
| C3 | 热畸变（refraction） |
| C4 | 火星（embers） |
| C5 | 柴堆几何 + 余烬自发光材质 |
| C6 | 烟层（与 B2 同源） |

## 3. 分批实施 + 验收指标

顺序（每补一条出一次 A/B + 量化，达标才进下一条）：

| 阶段 | 内容 | 主要指标 |
|---|---|---|
| **P0** | **A/B 基准台**（本 PR）：钉帧钉相机 + 参考帧入库 + 指标脚本 + 基线对照 | 产出可复现的并排图 + 指标 |
| P1 | A1 + A2：重转 campfire（火/温度/烟 三分）+ 边界淡出 | 烟柱出现；色阶直方图向参考靠拢 |
| P2 | B1：传递函数拟合（黑体 + 发射曲线 + exposure） | 色阶 / 均值 RGB 距离下降 |
| P3 | B2：烟（消光 + 受光散射） | 烟区亮度剖面接近参考 |
| P4 | A3 + B3：高分辨率 + 采样质量 | 细节/去块；发光像素分布 |
| P5 | B5 + B6：合成 + 时间稳定 | 稳定性（帧间差） |
| P6 | C1..C6：附件层 | 对齐 §1.2 照片靶子 |
| 终局 | 本地自烘等价 VDB（含 density/heat/flame），走同一 A/B 达标 | 全套指标 |

### 3.1 统一量化指标（`tools/campfire_ab/ab_metrics.py`）

以「亮度阈值」取前景，双方同法：

1. **形状**：包围盒高宽比 `h/w`、前景面积占比 `%`。
2. **颜色**：前景均值 RGB、暖色相直方图、近白（>230）占比。
3. **竖向亮度剖面**：前景归一化后逐带平均亮度（火能量沿高度分布）。
4. （可选）对齐后轮廓 IoU。

> 判据口径：**“不弱于”= 上述指标朝参考单调收敛，且无回归**；每阶段记录数值。

### 3.2 逐帧 A/B（自动化 diff 范式）—— `ab_seq.py`

单帧 A/B 只能看“某一瞬间像不像”；真正的验收门禁是**逐帧**跑同一套指标：

1. **纯数值、无需 vision 模型** ⇒ 确定性、可无人值守，P1..P6 每补一条机制就看各
   指标曲线是否朝参考单调收敛（**自动验收门禁**）。
2. **只有逐帧才看得见的问题**：闪烁（帧间差）、循环接缝、烟随时间的演化。
3. **顺带验证帧对应**：`资产帧 k ↔ 官方帧 60+k` 是假设；映射错则曲线跳/乱，
   这条工具本身就是验证器。

产出：逐帧指标表（`ab_seq.csv`）+ 竖排拼图（`strip.png`）。

逐帧看，两个取景无关的硬指标稳定暴露差距：**h/w 差 ~2×（我们太扁）**、

> 只能同侧自比。真·逐像素 diff 需先做相机/透视对齐 + 归一化（P0.5）。

## 4. P0 交付（本 PR）

1. **基准台**：`tools/jpov/tools/campfire_ab/`
   - `fetch_reference.py` —— 从官方 mp4 抽参考帧（CC0）入库；
   - `reference/` —— 已入库的参考帧（缩略）；
   - `ab_metrics.py` —— 指标 + 并排对照图；
   - `run_ab.sh` —— 端到端：抓 JPOV 孤立火 → 比对。
2. **viewer 的 A/B 模式**：`--ab-capture <out.png> [--ab-frame N] [--ab-box M]`
   —— 钉帧 + 钉相机（正面）+ 纯黑背景 + 居中火盒（只留孤立火）。
3. **逐帧 A/B 范式**：`tools/jpov/tools/campfire_ab/ab_seq.py`（逐帧 diff 表 + 拼图）。
4. **基线对照**：`tools/jpov/tools/campfire_ab/baseline/`（P0 时刻的差距快照，单帧 + 逐帧）。

## 5. 已知简化（P0 范围内，不阻塞）

- A/B 火盒用**立方盒**（`--ab-box` 给最大边），未按资产 `dims × voxel_m` 逐轴还原
  —— campfire 近乎立方（1.12×1.22×1.06 m），差异可忽略；逐轴盒归 A3。
- A/B 用**正面固定相机**，与官方透视未做严格透视匹配；形状指标（h/w、剖面）
  不受影响，像素级对齐留到需要时再加。
- 参考帧**缩略入库**（供肉眼比对与仓库体积控制）；像素指标以缩略后双方同法计算，
  口径一致。
