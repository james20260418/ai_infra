# JPOV Froxel 体积雾 —— 屏幕空间摊销 Z 轴采样（设计草案）

> 状态：**设计草案（尚未实现）**。作者：James / Danis。日期：2026-10-09。
> 关联：`jpov_fire_fog_design.md`（点状雾 + 逐像素 ZDist）、`jpov_tpz_volumetric_fog_design.md`、`jpov_volumetric_fog_design.md`。
>
> 目标：把「沿 z 的体积散射积分」从「**每全屏像素 × 多次深度采样**」摊销到
> 「**低分辨率 froxel 网格 + 屏幕空间并行**」，根治当前 ZDist 管线的两个顽疾：
> ① 抖动噪声「从深度采样转嫁到屏幕空间」；② 「噪声 ↔ 糊掉 ray 结构」的矛盾（唯一去噪手段
> 屏幕高斯必然抹掉光柱的高频）。

---

## 0. TL;DR

三趟：

1. **Inject（可并行）**：把每个 froxel 的**局部源**算出来。
2. **Scatter（沿 z 有序前缀，可 O(log)）**：算出每个 froxel 的**累积 `(T, S)`**。
3. **Composite（O(1)）**：全屏像素直接查表 → `L_out = L_scene·T + S`。

froxel 网格 = 视锥对齐 3D：`Nxy`（低分辨率屏幕 tile）× `Nz`（**指数分布**的 z 切片）。
**MVP 参数（第一轮）：`Nz=256`、`tile=16×16`（k=1）、`near=0.1m`、`far=2000m`**。
用**「2D 铺砖」**把一个 3D froxel 柱编进**主 FBO 尺寸**的纹理里
（**不需要真正的 3D 纹理**）：一个 16×16 屏幕 tile 的 256 个像素，正好承载该柱的 256 个 z 切片。

Inject 做成**金字塔** `L1(满) → L2(½) → L3(¼) → L4(⅛)`：每级在 z 方向把上一级 **4 个 cell 合成 1 个**，
供 Scatter 用「大块跳 + 小块补」实现 **O(log Nz) 的有序前缀**，从而**全分辨率并行**算 Scatter。

---

## 1. 背景与动机

现有 `jpov_fire_fog_design.md` 管线：逐（低分辨率）屏幕像素沿视线叠加雾团的 z 段 → ZDist →
屏幕空间高斯去噪 → 合成。实测暴露：

- **噪声源头是「每像素沿 z 的深度样本数」**（M）。噪声 ∝ 1/√M，从深度方向漏进屏幕方向；
- **唯一事后去噪手段是屏幕空间高斯**，抹噪声必抹光柱高频 → 「噪声 ↔ 糊 ray」二选一；
- **降采样 N>1** 让整幅亮度场低频「柳絮状」糊。

⇒ 正解：**把「沿 z 的积分」显式摊销到低分辨率 froxel 网格 + 屏幕空间并行**，而不是靠事后模糊。

> 本设计即业界 **froxel volumetric fog**（Wronski 2014, SIGGRAPH；Frostbite/Hillaire 2015）的
> 一套**屏幕空间落地变体**（用 2D 铺砖替代 3D 纹理，用金字塔并行化 scatter）。

## 2. 核心：inject / scatter / apply 与「合成算子」

### 2.1 三趟职责

| 趟 | 并行性 | 输入 | 输出 | 说明 |
|---|---|---|---|---|
| **Inject** | 可乱序、可并行 | 雾团/光照/阴影 | 每 froxel 的**局部源** | 昂贵（采光照/相位/CSM）但只算一遍 |
| **Scatter** | 沿 z **有序前缀**（本设计用金字塔并行化） | inject | 每 froxel 的**累积 `(T,S)`** | 前缀积/前缀和，只跑低分辨率×Nz |
| **Composite** | 全并行、**O(1)** | scatter | 屏幕颜色 | 逐像素查表 `L_scene·T + S` |

### 2.2 合成算子（**可结合、不可交换**）★

一个「段」（froxel / 块）用一对 `(T, S)` 表示：

- `T` = 该段**透射率** = `exp(−τ)`；
- `S` = 该段**内散射源**（在 over 意义上「累到段首」的加权和）。

**按 z 序（近→远）合并 A、B**（A 在前）：

```
T_AB = T_A · T_B
S_AB = S_A + T_A · S_B          （等价：τ=τ_A+τ_B，S=S_A+exp(−τ_A)·S_B）
```

- 这个算子**可结合**（能两两合并 ⇒ 可并行 scan），但**不可交换**（顺序必须保持 z 序）。
- **叶子（单个 froxel 切片）**：`Δτ = σ·Δz`；`S_leaf = L_in·(1 − exp(−Δτ))`
  （thin 近似 `≈ L_in·Δτ`；Frostbite 用「切片内 z 积分」更准）。

### 2.3 为什么能 O(1) 合成 + 区间可反解

scatter 把**累积对** `(T_cum(z), S_cum(z))`（**从相机 z=0 到深度 z**）物化。于是：

- 像素合成：`L_out = L_scene · T_cum(Z) + S_cum(Z)`；
- **任意区间 `[z1,z2]`** 都能 O(1) 反解（用于多层透明 / 厚玻璃「在雾弦上砍几刀」）：
  ```
  T_[z1,z2] = T_cum(z2) / T_cum(z1)
  S_[z1,z2] = ( S_cum(z2) − S_cum(z1) ) / T_cum(z1)
  ```

> ⚠️ **前提**：该介质必须**已经 inject 进网格**、且**网格 z 分辨率解析得动它**
> （介质 z 跨度 ≫ 该深度切片厚度）。**薄介质**（厚度 < 切片厚度）网格表示不了 ⇒
> 走 per-object 解析积分（见 §7）。

## 3. 数据布局（2D 铺砖编码 3D froxel）

- **Nz = 256**，tile = **16×16**（256 像素/柱）。
- 纹理 = **主 FBO 尺寸**、`RGBA32F`。每个 texel = 某个 froxel 的 **`(τ, S)`**：
  - `RGBA = (τ, S.r, S.g, S.b)` —— 1 个 float 存光学深度 τ，3 个 float 存 over 后的内散射源 S（HDR）。
- **映射**：屏幕像素落在 tile `(tx,ty)`、tile 内局部坐标 `(ix,iy)` ⇒ 该柱的**切片索引**
  `k = iy*16 + ix`（行主序）⇒ 由**指数 z 分布**得到切片的世界 z 区间 `[z_k, z_{k+1})`。
- 每个 texel 只在**其所属 tile 的柱**内；整块纹理 = `(Nxy) × Nz` 的 froxel，无需 3D 纹理。

> 前提：**Nz 必须等于 tile 像素数**（16×16=256）。若要改 Nz，需同步改 tile 尺寸。

---

### 3.1 z 分布（指数）与参数

**公式**（指数 / 几何分布）：

- 切片边界：`z_k = near · (far/near)^(k/Nz)`，`k = 0…Nz`（`z_0=near`、`z_Nz=far`）；
- **生长系数**（相邻切片倍率）：`R = (far/near)^(1/Nz)`；
- 切片厚度：`Δz_k = z_k·(R−1)` ⇒ **`Δz ∝ z`**；
- **反解**（按深度截断 / 定位切片）：`k(z) = Nz · ln(z/near) / ln(far/near)`；
- 切片中点：`z_mid(k) = near·(far/near)^((k+0.5)/Nz)`。

**性质**：`Δz ∝ z` ⇒ 每片在屏幕上的投影厚度 ≈ 常数（「屏幕等厚的深度切片」）⇒ 近处精确、远处不浪费。

**MVP 参数（第一轮）**：`Nz=256`、`tile=16×16`、`k=1`、`near=0.1m`、`far=2000m`。
⇒ `R = (20000)^(1/256) ≈ 1.0394`，末片世界厚度 ≈ **76m**（远场变粗但覆盖无虞）。

**注意**：`near` 别设太小（浪费近端）；要超远（km 级 / 云）→ 用**级联体积（cascade）**或**带幂次的分布**
`z = near·(far/near)^(s^p)`（p<1 把精度往远处挪）**先调分布**，再考虑加 Nz。

## 4. Pass 划分

### 4.1 L1 inject（主 FBO 尺寸，RGBA32F）

- 逐像素：**取 tile 中心视线**（froxel 是「整柱一个值」，不是像素自己的视线）；
- 按自身局部 id `(ix,iy) → k`，反推该 froxel 的**世界 z 区间**；
- 遍历**该 tile 的候选雾团**（复用屏幕 tile 剪枝 `convex_hull_tiles` / `BuildTileFogIndexData`），
  对与**本 froxel 世界体**相交者，累计其 `Δτ` 与 `S_leaf`（§2.2）；
- 写入本像素 = 该 froxel 的局部 `(τ, S)`。
- 空 froxel ⇒ 恒等 `(τ=0, S=0)`（`T=1, S=0`）。

### 4.2 L2 / L3 / L4 inject（金字塔，z 方向归约）

| 级 | 纹理尺寸 | tile | 每 cell = 上一级 | 覆盖的原始 froxel |
|---|---|---|---|---|
| L1 | 满 (W×H) | 16×16 | — | 1 |
| L2 | ½ (W/2×H/2) | 8×8 | 4 个 | 4 |
| L3 | ¼ (W/4×H/4) | 4×4 | 4 个 | 16 |
| L4 | ⅛ (W/8×H/8) | 2×2 | 4 个 | 64 |

- **每级 tile 数恒定**（屏幕减半 × tile 减半 ⇒ 仍是 `(W/16)×(H/16)` 个柱）。
- **渲染**：参考上一级——由屏幕像素 id 反推其在上一级纹理里对应的 **4 个 texel**（同一柱、z 上相邻，
  **可能跨行**），用 §2.2 的 **over 算子按 z 序合并**，写入本级。
- 用途：供 Scatter「**大块跳**」用。

### 4.3 Scatter（主 FBO 尺寸，布局同 L1）

- 逐像素 = 某柱的某切片 `k`，**并行**求**累积对** `(T_cum(k), S_cum(k))`（从 z=0 到该切片）。
- **求法（O(log Nz)，金字塔加速）**：把 `k` 按 **base-4** 分解
  `k = a3·64 + a2·16 + a1·4 + a0`，则
  ```
  prefix[0,k) = 依次 over-合成：
      L4 的 [0, a3) 个 cell        （覆盖 [0, 64·a3)）
    ⊗ L3 的 [4·a3, 4·a3+a2) 个      （覆盖 [64·a3, 64·a3+16·a2)）
    ⊗ L2 的 [16·a3+4·a2, +a1) 个
    ⊗ L1 的 [64·a3+16·a2+4·a1, +a0) 个
  ```
  每层 ≤ 3 个 cell ⇒ 总 ≤ ~12 次 over-合成 = **O(log Nz)**。
- **必须按 z 序合并**（算子不可交换）。结果写回 scatter 纹理对应 texel。

### 4.4 Composite（主 FBO 尺寸）

- 逐像素：用自身**屏幕 tile 坐标**找到 `Nxy` 空间的**最近邻 4 个 tile**，取其 scatter 列；
- 依**像素深度 z** 取「截断后的 `(T,S)`」——**在 z 方向对相邻两切片插值**（★见 §5），
  再对 4 邻 tile **双线性** ⇒ 得到该像素的 `(T,S)`；
- 合成：`L_out = L_scene · T + S`（就地混合到 HDR FBO，同现有 `GL_ONE/GL_SRC_ALPHA` 套路）。

---

## 5. 关键约定与坑（**检查结论**）

1. ★ **inject/各层/scatter 存的是「over 合成的 `(τ, S)`」，不是「可加的 Ed」**。
   - 合成必须用 §2.2 的 over 算子 `S=S_A+exp(−τ_A)·S_B`。
   - 若像现有 ZDist 那样只存可加 `(τd, Ed)`，合成端要逐段 `exp` 加权 ⇒ `O(Nz)`，**违背 O(1) 合成**。
   - （对照：ZDist 把 `(τd,Ed)` 可加存、末端积分时再 exp；froxel 为 O(1) 把 exp **提前烘进 S**。）
2. ★ **Composite 需要「z 向插值」**（不只是 Nxy 双线性）：像素深度落在两切片之间，
   取相邻两切片的 `(T,S)` 先按 z 插值，再与 Nxy 4 邻域做（合计 2×4=8 采样，或 2×2×2）。
3. **算子可结合、不可交换** ⇒ 金字塔块合成 / 前缀 / base-4 取块，**一律按 z 序**。
4. **Nz = tile 像素数**（16×16=256）；改 Nz 要同步改 tile 与铺法。
5. **L1 inject 用 tile 中心视线**（不是像素自己视线）；froxel = 整柱一个值。
6. **空 froxel = 恒等**（τ=0,S=0，T=1,S=0）。
7. **薄/锐介质**（厚玻璃若厚度<切片厚度）：网格表示不了 ⇒ per-object 解析（§7）。

---

## 6. 计算量与并行性

- **Inject**：`Nxy × Nz`（= `(W/16)(H/16) × 256`）次，**全并行**；金字塔附加 `O(Nxy·Nz)` 次合并。
- **Scatter**：`Nxy × Nz` 次，**全并行**，每像素 `O(log Nz)` 次合成（**关键：把串行前缀 log 掉**）。
- **Composite**：`W×H` 次，每像素 O(1)（8 次采样）。
- 对比现有逐像素 ZDist：把「每全屏像素 × 深度步数」降到「低分辨率 froxel 一次」。

---

## 7. 边界与特例

- **薄/锐介质（无折射厚玻璃、烟片、光柱本身）**：不塞进粗网格（会漏/糊）。
  走 **per-object 解析积分**（前后面深度 → 闭式 Beer-Lambert）或 **hero pass**，最后合成。
  判据：「介质 z 尺度 ≫ 该深度切片厚度」才进网格。
- **表面型透明（玻璃只反射/菲涅尔）**：不进 froxel；Composite 按**该表面精确深度**截前缀
  （froxel 低分辨率只软化「雾自身」细节，**不**软化「雾被物体裁切」的剪影）。
- **多层透明**：逐层按自身深度读前缀（§2.3 区间反解），front-to-back 合成。
- **光照**：inject 阶段接现有 CSM（太阳）+ ambient + 相位（god ray），与 `jpov_fire_fog_design.md` 同源。

## 8. 与现有 ZDist 管线的关系

| | 现有 ZDist（`jpov_fire_fog_design.md`） | 本设计（froxel） |
|---|---|---|
| z 表示 | 每像素**自适应断点 ≤8** | 固定密集**指数 z 网格 Nz** |
| 载体 | 6 texel/像素打包 | 主 FBO 尺寸 2D 铺砖（编 3D froxel） |
| 去噪 | 屏幕空间高斯（会糊 ray） | **源头摊销**（每个 froxel 一次），无事后糊 |
| 串行 | 逐像素沿 z 段累加 | Scatter 前缀**并行化**（金字塔 O(log)） |
| 共性 | 列方向都是「累积 τ/Ed 随 z 单调递增」= 同族 |

## 10. 后续 / 可选（业界 low-hanging fruit，备忘，不阻塞主线）

> 简单引用，供后续按需加。

- **① STBN（时空蓝噪声）+ 时域重投影 / EMA**：把抖动从「每帧白噪」变成「空间+时间都蓝噪声」的采样，
  再配历史帧累积 ⇒ 收敛快、感知误差小，**不必靠大高斯把光柱糊掉**（正对本管线早期「噪声↔糊 ray」的痛点）。
  — Wolfe 2022（`arXiv:2112.09629`）、FAST（Donnelly 2024）、Wronski 2014（froxel 时域重投影）。
- **② 深度感知双边上采样**（低分辨率 froxel → 全屏）：按 depth（可选 normal）加权，避免雾糊到物体边缘。
  — Wronski 2014 / Frostbite（Hillaire 2015）/ TLOU2（2020）。
- **③ 双叶 HG / Mie 相位**（g ≈ 0.76）：比单叶 HG 更接近真实前向散射，god ray 更自然；
  且光柱由**介质积分自然产生**，无需单独的 radial blur。— Schneider 2015（Horizon）/ Hillaire 2015。

### 其它记档（低优先）
- **级联体积（cascaded volume）** 扩 range（Frostbite）；**detail spread / 多 octave**（Godot / Wronski，收益有限）；
- **光照低频化 + 缓存**（TLOU2 探针树 ambient、sun light cache / snapshot）；**光源剔除**给体素用；
- **async compute / indirect dispatch 只算可见·新暴露 froxel**（TLOU2）；
- **粒子/透明表面体素化进 extinction volume**（Frostbite 的 unified 卖点）。

> ⚠️ 已知坑：体素沿视线很长 ⇒ **深度泄漏**（光从几何后面漏出）；**Composite 必须严格按像素深度截断**
> （本设计 §4.4 已如此）；时域重投影需处理 **newly-revealed areas**。

## 附：术语

- **froxel** = frustum voxel：视锥对齐的 3D 体素。
- **inject** = 写入每 froxel 的局部源（σ/L_in）。
- **scatter** = 沿 z 累加成累积 `(T,S)`。
- **over 算子** = 前向合成 `(T_AB,S_AB)=(T_A·T_B, S_A+T_A·S_B)`（可结合、不可交换）。
