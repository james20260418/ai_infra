## 0. 一句话

> **范围（2026-11-23 定）**：整体结构按「Source / Query / PQ 积分」三件套搭；
> **内容只做水**（水皮 + 水体），WBO 三源与雾团 froxel 放弃（§2.3）。

把反射拆成三个可以分别验证的东西：

1. **Source** —— 一个**不含任何镜面**的场景采样源（实心 G-buffer + 透明等效层 + 介质）；
2. **Query** —— 一张「谁需要镜面答案」的表（P / N / R / 带宽 / 权重）；
3. **PQ 积分** —— 沿 R 把**表面项 + 介质项**合成一条辐亮度。

镜面 BRDF、env 兜底、Fresnel、AO **全部留在消费端**，而且**只算一次**。

## 1. 为什么（现有三笔债）

| # | 债 | 现状 | 后果 |
|---|---|---|---|
| 1 | **替换估计器** | 融合 = `color − s_env(P,R) + SSR`（`ssr_integration.h` 顶部注释） | 减法要求两份公式**逐字节一致**；`distributionGGX` 的护栏口径已经在 PR #262 出过一次血（水皮被压低 1086×） |
| 2 | **反射里没有雾、没有水** | SSR 的输入是「半透明/粒子/雾/Bloom 之前」的颜色 | 湿地面在雾里「反射里没有雾」；`known_issue §10.11` 同类问题 |
| 3 | **透明完全缺席 + 属性不准** | SSR 明文非目标：不做透明反射；`attr_mat` 的 `base_color` 用的是材质常量 | 玻璃后的倒影不衰减；带纹理的反射体在倒影里的高光是错的 |

SSRV2 三条一起消：源出厂就没有镜面（债 1 变成纯加法）、介质进 PQ 积分（债 2；本版只做水）、
透明从「完全缺席」缩到「只做水皮」（债 3 的一大半，§2.3）。

## 2. 目标 / 非目标

### 2.1 目标

| 目标 | 含义 |
|---|---|
| **单一方向口径** | 所有方向依赖量都在模块内用**PQ 射线自己的方向**求值（§4），不许复用相机口径的烘焙值 —— 除非明写为近似 |
| **镜面只算一次** | 源不含镜面；命中点的镜面项由 SSRV2 现算；消费端只乘 Fresnel/AO 一次 |
| **介质可解释** | 每条介质来源在文档里都有明确的可采样性和误差界（**本版只保留精确路径**，见 §2.3） |
| **确定性** | 同输入同输出，无历史、无抖动、无时序，可进 gold |
| **可分期** | P1…P5 每期单独出货、每期都能造 gold（§7） |

### 2.2 非目标

- **不做多次弹射**：一次弹射即止，命中点不再发射线。
- **不做透明靶子**：透明层永远不是反射的命中对象（理由见 §3.2，这是本文最重要的一条边界）。
- **不做真正的 3D 密度场**：froxel 不是体素场（见 §3.4）。
- **不做屏幕外重建 / TAA / 降噪**（沿用 #241 的口径：每帧从零构建）。
- **不做 GI**：命中点的漫反射来自源的 diffuse 颜色，不追第二跳。

### 2.3 本版范围（2026-11-23 Danis 定：退而求其次，只留水）

| 内容 | 进 SSRV2？ | 理由 |
|---|---|---|
| 实心 G-buffer（depth / normal / F0+rough / diffuse-only） | ✅ | 反射本体 |
| **水体介质**（半空间，闭式） | ✅ | 精确、解析、零烘焙 |
| **水皮**（解析高度场靶子） | ✅ | 唯一「几何含义还在」的透明类表面（§3.5） |
| 远距/仰角雾（不吃光、各向同性） | ⬜ **待确认**（建议 ✅） | 零风险：与水体共用同一段积分；删了反而多一条分支 |
| 三个 WBO 源（粒子 / 条带 / 体积火 / 玻璃） | ❌ | 等效层无几何；且只有玻璃有 `z̄`、统一层装置还没接（§3.2.1） |
| 雾团 froxel | ❌ | 不是体积场（相机射线累积）；相位/阴影/长度三重近似（§3.4） |
| 透明面纱 / 多层 query | ❌ | 依赖上面两项 |

> **这个削减的最大收益**：SSRV2 的介质部分只剩**一条精确路径**（水），
> 没有「近似类」，也没有需要维护的第二套口径。§3.2 / §3.4 / §4.2 / §4.4 里关于
> WBO 与雾团的分析**保留作为将来依据**（不要删），但**本版不实现**。

## 3. 三个概念

### 3.1 SSRV2Source（采样源）

| 部件 | 内容 | 现状 | 结论 |
|---|---|---|---|
| **实心** 深度 | `scene_depth_tex`（R32F，`gl_FragCoord.z`） | 已有 | 直接用 |
| **实心** 法线 | `attr_tex`（rgb=视空间法线，a=掩码） | 已有 | 直接用 |
| **实心** 材质 | `attr_mat_tex`（rgb=F0，a=roughness） | 已有，但 **`base_color` 用材质常量** | **要补逐像素材质**（P1/P4） |
| **实心** 颜色 | `diffuse-only`（**不含任何镜面**） | **没有**（现在只有含镜面的 HDR 色） | **新增 MRT#2**（P1） |
| **透明** | `TransparentLayer{accum, reveal, depth}` → 等效层 `(Cavg, cov, z̄)` | 已有 | ❌ 本版不用（§2.3） |
| **介质** | 远景雾 / 雾团 froxel / 水体半空间 | 已有 | 三类可采样性不同（§3.4） |

#### 3.1.1 为什么源里绝对不能有镜面

两条独立的理由，任一条都足够：

1. **双计**：源的镜面是「按相机方向算的」。沿 R 采样它，等于把「给 V 的答案」当成「沿 R 的答案」用 —— 而在反射里再叠一次 SSRV2 自己的镜面，就是两份镜面相加。
2. **方向错配**：镜面项对出射方向极其敏感（GGX 峰宽 `a2`，水皮 `a2≈5.4e-6`）。相机方向与 R 的夹角在掠射时可以是 90°，这个量**不是误差，是另一个物理量**。

> **推论**：`color − s_env + SSR` 这种「先加再减」的路线必须退休。减得准不准取决于两份公式完全一致，
> 而 JPOV 现在有**三份** `distributionGGX`（object3d / instanced / skeleton）+ 融合里第四份。
> 这是 bug 类别，不是 bug。

### 3.2 透明层：只做「衰减 + 面纱」，永不做靶子

> **2026-11-23 范围更新：本节整节已出本版范围（§2.3）。**
> 保留分析作为将来依据 —— 如果哪天要把粒子/火/玻璃放进反射，就先读这一节和 3.2.1。

**这是本文唯一的硬边界，请确认后再往下读。**

现在的 `TransparentLayer` 是**已经压掉内部结构**的等效层：

```
Cavg = accum.rgb / accum.a      cov = 1 − reveal        z̄ = depth / accum.a
```

一个像素只代表**一个**层，没有逐层深度、没有法线、没有逐层 alpha。后果是确定的：

| 想做的事 | 可行性 |
|---|---|
| 射线穿过时按 `cov` 吃掉透射率（**衰减**） | ✅ 精确，白送 |
| 射线穿过时加一份 `Cavg·cov`（**面纱**） | ✅ 近似（见 §4.4） |
| 把透明层当**反射靶子**（拿它的法线算 BRDF / 让射线停在那里） | ❌ 做不到：没有法线、没有几何 |

要做靶子，只有两条路，都不要走：

- **逐像素链表 / depth peeling**：内存与带宽另一个量级，而且 SSRV2 每像素**只负担得起 1~2 条射线**，采到第 3 层也没用；
- **把 WBO 三附件当靶子**：它在语义上是「沿相机视线的合成结果」，根本不是表面。

> **契约**：透明层只能**衰减 + 面纱**，且它的贡献只与 `(cov, Cavg, z̄)` 有关。
> 这条也守住了「模块只报事实」的分工：反射是**表面**属性，WBO 不掌握表面。

#### 3.2.1 现状复核（2026-11-23）：比上面这张表还要更糟一点

三条实测事实，P5 排期前必须先认：

| # | 事实 | 影响 |
|---|---|---|
| a | **没有任何生产者写正态**。透明生产者的 FS 输出只有 `FragAccum / FragReveal / FragAdd`（`particles:170-172`、`volume_fire:108-109`） | 「没法线」是结论，不是猜测 |
| b | **只有玻璃申请了代表深度**（particles:85 / strip:386 / volume_fire:166 全传 `with_depth=false`） | 面纱的「穿层判定」对粒子/条带/火**没有 `z̄` 可用** |
| c | ~~统一层装置未接~~ **（2026-11-23 更正）**：`main` 上的统一层合成**已经接了，且只接了水皮** —— `renderer.cc:2129 layers.Add(water_skin_renderer_.layer())`，触发条件 `run_medium_composite = run_fog \|\| water_skin_on \|\| water_medium_on`。粒子/条带/火仍是各自 resolve（在层集合构造之前就合成掉了） | 水皮这条路**是现成的**；另外三个源没接。之前那句「空集」是在旧分支（`feature/20261106-jpov-lux-glass-design`）上读到的，**不适用于 main** |

> **关键区分：补一个 normal 通道并不能让它变成靶子。**
> WBO 的法线只能是「按 `α·w` 加权平均」—— 多片交叠时它是**无关表面的平均**，归一化后没有几何意义；
> 剪影与掠射处还会噪声爆掉。病症是「没法线」，病因是「等效层」（内部结构已丢）。
> 真要让透明当靶子，唯一便宜的路是**额外一张「最表皮 G-buffer」**（深度测试只留最近一层，
> 存 depth/normal/albedo/alpha），而不是往 WBO 里塞通道。
> 它也有明确失效：**沿相机最前 ≠ 沿反射射线最前** —— 屏幕空间方法的固有边界，不是实现 bug。
> 本文仍不做（§2.2），但把这条路记在这里，免得将来重新发明。

### 3.3 SSRV2Query（谁需要镜面答案）

```cpp
struct SsrV2Query {
    Vec3f P_view;       // 着色点（视空间）
    Vec3f N_view;       // 该点的法线
    Vec3f R_view;       // 反射方向（= reflect(-V, N)，已归一）
    float a2;           // GGX 带宽（含光源角半径项，见 docs/jpov_specular_bandwidth.md）
    float weight;       // 该 query 的权重（实心 pass = 1；透明片元 = α·w）
    float fresnel;      // 消费端要乘的 F（模块不乘，见契约 5.2）
    uint8 pass_id;      // 0 = 实心 pass，1 = 透明 pass
};
```

**「P 点在哪」= 每个 shading point 一个**，不是每层一个抽象。所以：

| 问题 | 答案 |
|---|---|
| 实心 pass 出几个 query？ | 每个可见表面像素 1 个 |
| 透明 pass 出几个 query？ | 物理上**每个透明片元 1 个**（每片是独立表面，有自己的 BRDF） |
| v1 保留几个？ | **每像素只保留 `α·w` 最大的那 1 个**（top-1 by weight），其余丢弃并计数 |

> v1 选 top-1 的理由：多层 query 的收益（同一像素两片玻璃各自的镜面）远小于成本（每层一条射线），
> 而**丢弃必须可观测**（统计计数），不能静默。

### 3.4 介质：三类，可采样性完全不同

| 来源 | 形态 | 光消费 | 沿 PQ 的可采样性 |
|---|---|---|---|
| **远景雾**（`DistanceFog`，PR #263 —— **该 PR 在本仓库尚未合入**，合入前对应 `src/horizon_fog` 的仰角雾） | 全局均质 + 软边权重 `w(P)` | **不吃光**（用户配的色就是色） | ✅ **精确**：逐步/解析积分，`∫σ·w(t)dt` 与方向无关 |
| **雾团**（froxel，`fog_renderer`） | **相机射线累积**（每柱一个值，用 tile 中心视线） | 吃环境 + 太阳×CSM + 点光，**相位已烘焙** | ⚠️ **近似**（三重近似，见 §4.2 / §8.1） |
| **水体**（`WaterCommand` 半空间） | 均质 `σa/σs` + HG，`y ≤ level_y` | 吃太阳 + ambient | ✅ **精确**：闭式积分，相位按 PQ 方向现算 |

**关键认知：froxel 不是体积场。** `kFogInjectBody` 里 `rd = texelFetch(uTileRayTex, tile)`，
即**整柱一个 tile 中心视线**，存下来的是「这条相机射线在该 z-slab 上的线积分 `(τ_k, S_k)`」。
它不是「逐 voxel 的密度」，所以任何**别的方向**的射线穿过来，都只能做**重标定**：

```
σ̄_k  = τ_k / len_cam(k)                      // len_cam 由 zk、zk1、tile 中心视线解析得到
τ_PQ = σ̄_k · len_PQ(k)                       // PQ 射线在该 slab 内的长度
```

误差来源有三：① 沿柱平均的 σ 与斜穿的真实 σ 不同；② `CsmShadow(p)` 的 p 是相机射线上的 slab 中点；
③ 相位烘焙（§4.2）。

> **2026-11-23：雾团已出本版范围（§2.3）。** 上面的重标定推导保留，供将来要做时直接接上。

### 3.5 水皮：本文唯一的「解析靶子」（2026-11-23 纳入范围）

为什么它是本轮唯一值得做的透明类内容：

1. **几何含义还在**：高度场 `h(x,z,t)` 是解析的，交点与法线都能算，不依赖任何「等效层」近似。
2. **不经过 WBO**：水皮虽然是透明 pass，但它有**确定的解析表面**，不是「内部结构被压掉」的合成结果。
3. **它在屏幕空间里根本不存在**：`scene_depth_tex` **没有水**（水不写场景深度）
   ⇒ **今天的 SSR 会直接穿过湖面**，反射到湖底或湖后的东西。这是**现存的可见 bug**，不是新功能。
4. **零光照烘焙**：水皮着色是解析的（`F·探针 + 太阳的像`），不需要任何相位缓存。

所以水皮进 SSRV2 的方式是：**求交 = 解析；着色 = 解析；不弹射。**

> 细节（容易被误判）：水皮在自己的 WBO 里**确实申请了代表深度**（`water_skin_renderer.cc:100`
> `with_depth=true`，因为它要和雾做深度合成）。但那是**另一个纹理**里的 `Σ(z·α·w)/Σ(α·w)`，
> 不是 `scene_depth_tex`；而且**没有法线**。单层时它≈水面深度，可以当**交叉校验**，
> 但**不能当靶子**（靶子必须有法线才能着色）。

#### 3.5.1 射线-水皮求交

复用 PR #261 的 `water_wave_shader.h::WaveSurfaceHit(cam, ray_dir, level, footprint, inout t, out pos, out normal)`
—— 它**已经是参数化的**（不依赖 `uCamPos`），把 `cam=P, ray_dir=R` 塞进去即可，**不需要写新的求交代码**。

求交本身是**二分 12 次**（`kWaveBisectIterations`），不是 Newton —— 理由是 `f'` 在波谷/陡坡处
→ 0 会跳根（表现为法线噪点），二分区间两端必变号所以全局收敛。分前先定平面解 `t_plane`，
区间取 `[t_plane − ΣA/|R.y|, t_plane + ΣA/|R.y|]`。

但 PQ 射线与相机射线有 **三** 个必须处理的差异：

| 差异 | 后果 | 处理 |
|---|---|---|
| **① `WaveFAt` 用 `length(p.xz − cam.xz)` 算 fade** | 把 `cam` 换成 `P`，fade 基准就从相机变成了 P ⇒ **同一个世界点的波幅随"哪条射线来求值"而不同** ⇒ 接缝/闪烁 | **必须解耦**：求交起点与 fade 参考点分开传（加 `fade_ref` 参数）。**本文最易漏的一处** |
| **② 起点不在相机** | `P` 可能在水面上方很高 ⇒ 平面 `t` 极大、掠射时差几公里 | 沿用 #261 的 `t_plane` 教训；二分天然比 Newton 稳 |
| **③ 可能多次穿面** | 波谷处掠射射线能与高度场相交多次 | 二分只保证"区间内有一个根"；无变号时**回退平面解**（已有兜底分支），不要贪心取最后一个根 |

**成本与精确早退**：一次求交 ≈（2 端点 + 12 二分）= 14 次高度场求值 × ≤8 波 ≈ 100+ 次 sin/cos。
可以**零成本干掉绝大多数像素**（精确判据，不是启发式）：

```
P.y > level_y + ΣA  且  R.y ≥ 0   ⇒ 射线向上、永远碰不到水面 ⇒ 跳过求交
```

只有「水上的反射体、且反射方向朝下」才需要真求交。

> 补充：**波表不是 64 个波**。`WaterWaves::kMaxWaves = 8`，GLSL 里是 `for (i < 8)`；
> 且 `(k, ω, amp, phase)` 是 **CPU 每帧算一次**（`uWaveL[]` uniform），shader 只做求和
> ⇒ **波表不会算两遍**。但**高度场求值**必须重算 —— 相机射线交点与 PQ 交点本来就是不同的点。

#### 3.5.2 顺序规则（必须有，否则会漏）

水皮不在深度图里 ⇒ 水皮命中与深度命中**必须按距离比较**：

```
s_water = 解析交点的像素距离；  s_depth = march 的命中距离
if (s_water < s_depth) 命中水皮（表面项）  else 命中实心
```

不做这一步就会出现「反射里的湖面被湖底穿透」—— 正是今天的现象。

#### 3.5.3 水皮的着色（表面项）

```
L_water(hit; →P) = F(θ')·probe(reflect(−R, N_w)) + 太阳的像(N_w, −R)
```

`θ'` 与 `N_w` 都按 **PQ 射线**求（§4.3 同一条纪律）。**不弹射**：水皮的反射走探针，不入 SSR（否则是递归）。

#### 3.5.4 已知 corner case（「理论上不容易」要打个折：五条）

| # | corner case | 处理 |
|---|---|---|
| a | **太阳的像需要像素足迹**（`dFdx(H)`），但解析命中点**没有导数** | 用主像素足迹沿射线投影，或退回固定角尺寸 —— **这是本方案唯一真正别扭的地方** |
| b | **相机在水下**（TIR 环内水皮是镜子） | v1 **不支持**：相机在水下时水皮不作为靶子（沿用「水下没有雾」的同类约定） |
| c | **不做折射**：射线进水后方向不变 | 因为 (i) 命中水皮即终止、(ii) 不做水下相机 ⇒ v1 里不会出现「射线在水里走」 |
| d | **反射体本身就是水皮**（水映景）：`R.y` 很小、起点就在水面 | 波高范围 ±振幅内或 `dot(R,N_w) < 0` ⇒ **跳过水皮求交**（self-skip），否则立刻自交 |
| e | 波浪 vs 介质高度不一致（介质用 `level_y`，波高 O(10cm)） | 沿用 known_issue §10.12，误 O(波高) |

## 4. 🔴 方向依赖：一共三处，绝不许混

> 这一节直接回答 2026-11-23 的两个问题：
> **「froxel 的相位因子要不要记入？」「命中点的高光要不要记入？还是 PQ 线上只走各向同性光？」**
> **答：都要记入，而且必须用 PQ 射线自己的方向求值。PQ 线上不是「只走各向同性光」。**

### 4.1 总览

| # | 项 | 方向依赖强度 | 正确口径 | 我们现在的状态 |
|---|---|---|---|---|
| 1 | **介质散射** `σ_s·p(θ)·L_light` | 强（HG 可到几十倍） | `p` 的自变量用 **PQ 射线方向** | 雾团**烘焙了相机方向**；水体是现算的（可改）；远景雾无相位 |
| 2 | **命中点表面** `f_s(ω_l, ω_o)` | 强（`a2` 峰宽） | `ω_o = ` **指向 P 的方向 = −R** | 不存在（现在只取源颜色，不含镜面） |
| 3 | **面纱** `Cavg` | 中（Fresnel 掠射） | 理想是「沿 −R 求值」 | **做不到**：Cavg 是相机口径烘焙值（见 §4.4） |

### 4.2 介质项：相位必须记入，且不能用相机口径的缓存

> **适用范围**：远景雾无相位；水体是现算的（可直接换成 PQ 方向）；
> **雾团已出本版范围（§2.3）** —— 本节关于雾团烘焙的分析保留，作为将来依据。

单次散射的源项对**散射角**敏感：

```
L_in-scatter(x, →P) = σ_s(x) · ∫_{S²} p(ω_l → −R) · L_light(x, ω_l) dω_l
```

其中 `−R` 是「从 x 指向 P 的传播方向」（即把 PQ 射线**当成一条视线**看待）。
Henyey–Greenstein 对传播方向对称，所以直接把 R 塞进现有的 `SunPhase(vec3 rd)` 就够了：

```
SunPhase(R) = HgPhase(dot(R, −uSunDir), g)   // 与 fog_shader.h:352 完全同一个函数
```

**为什么不能复用现成的 froxel 值**：`kFogInjectBody` 里

```glsl
Llight += uSunColor * uSunIntensity * SunPhase(rd) * sh;              // :447，rd = 相机射线
Llight += fl.color * fl.intensity * atten_l * HgPhase(mu, uSunPhaseG); // :459，mu = dot(rd, 光源方向)
```

`rd` 是 **tile 中心相机视线**。g=0（各向同性）时两者相同；g=0.5~0.95 时，
「背对太阳看、但反射朝太阳」这种构型下比值 `p(θ_R)/p(θ_cam)` 可以是**几倍到几十倍**。
这不是小误差 —— 它恰好是「湿地面在背光侧该不该出现太阳的辉光」这个可见现象。

**修法（二选一；当前均在范围外）**：

| 方案 | 做法 | 代价 |
|---|---|---|
| **A（推荐）** | inject 拆两路：`S_dir`（太阳 + 点光，**不乘相位**）、`S_iso`（ambient + emission + 远景雾）；归约/前缀各带一路；消费端 `S = S_iso + S_dir·p(θ_R)` | 金字塔多一路（+50% 内存/带宽），机械改动 |
| **B（更省，误差更大）** | 不拆，消费端乘一个修正比 `p(θ_R)/p(θ_cam)` | 无法分离 ambient 与太阳，只有「纯太阳雾」时才近似成立 |

**v1 建议**：P3 先只做**水体 + 远景雾**（两者都精确，不需要改 fog 模块），
雾团走方案 A 时才需要 —> 已出本版范围（§2.3），留作将来依据。

> **点光雾**（`:459`）的相位同样烘焙了。即使做了方案 A，点光那路仍需逐光源方向 —— 
> 建议长期保持「点光雾按相机口径近似」，写进 known_issue，别在这里追求精确。

### 4.3 命中点表面项：`f_s(ω_l, −R)`，不是 `f_s(ω_l, −V)`

```
L_surf(hit; →P) = L_diff(hit)                              // 漫反射：相对安全，各向同性
                + f_s(N_hit, ω_l, −R) · L_l · V(hit)       // 镜面：出射方向 = −R
                + probe(reflect(−R, N_hit), ρ_hit)         // 环境：命中点自己的反射方向
```

三条必须写进契约：

1. **`ω_o = −R`**：从命中点指向 P，**不是相机的 V**。这意味着倒影里一个金属球的高光位置/强度
   与直接看它**本来就应该不同**。
2. **不许复用语源的答案**：源里该像素的镜面即使存在也是为 V 算的（而源里根本没有，§3.1.1）。
3. **这是 gold 的判读纪律**：review 时「反射里的球和本体看起来不一样」**不是 bug**。
   写进 §7 每期的验收说明里，否则一定会被当成回归报上来。

#### 4.3.1 现状（2026-11-23 核实）：完全没考虑，就是一行取色

`ssr_shader.h:410` 的命中取色是：

```glsl
rgb = texture(uColor, pos / uRes).rgb;   // 纯双线性，没有任何方向处理/重着色
```

拿到的色是命中像素**为相机方向着过的**：`f_s(ω_l, −V_hit)` + `probe(reflect(−V_hit, N), ρ)`。
物理上要的是 `f_s(ω_l, **−R**)` + `probe(reflect(**−R**, N), ρ)`。

**误差什么时候是 0（这个尤其危险）**：反射体法线正对相机（`N ∥ V`）时 `R = −V`，
命中点的 `−R` 与相机的 `V_hit` 恰好重合 ⇒ 误差为 0。
这正是最容易造的 gold（画面正中的平整镜面），它会把问题完全掩盖。

**误差什么时候最大**：

| 因素 | 误差 |
|---|---|
| 反射体掠射（`N·V → 0`） | `R` 与 `V` 夹角 →180°，命中点镜面**完全错位**（多出不该有的高光、丢掉该有的） |
| 命中面越光滑（`a2` 小） | 越致命（δ 附近） |
| 命中面粗糙（`a2` 大） | 方向性软，误差小 |
| 漫反射部分 | **无误差**（方向无关）—— 所以 SSR 整体“看着对”，只有高光是错的 |

**还有第二笔**：命中点的 env 镜面也是按相机方向求的，而且融合时**没有减掉**
（融合只减 P 自己的 env 估计）⇒ 双重错：位置错 + 口径没换。这是 P4 的另一个子项。

> 造视觉证据很便宜：一块平面镜 + 一个 `roughness≈0` 的金属球，从**掠射角**看 —— 
> 反射里球上的灯高光位置一定不对；换成正对相机看，误差消失（这正是 4.3.1 那条陷阱）。

**代价**：SSRV2 里要能拿到 lights texture + 一份 specular GLSL。
这就是**第 4 份 PBR 拷贝**的风险 —— 所以 **P1 必须先把三份 `distributionGGX` 收敛成一份共享片段**。
命中点的探针项**必须** include `src/env_specular.h` 的同一份 GLSL，禁止重写第二份（契约 5.6）。

### 4.4 面纱：本文唯一「违反源无镜面」的缺口，必须写清楚

> **2026-11-23：面纱已出本版范围（§2.3）** —— 连带着，契约 6.1 的那一条例外也一起消失了：
> **本版的源里没有任何镜面，没有任何例外**。本节保留作为将来依据。

`Cavg` 是透明 pass **按相机方向**着色并 WBO 合成的结果，它：

- 含该层**自己的镜面**（玻璃的 Fresnel 反射就在 `accum` 里）；
- 是**相机口径**的（换方向看同一片玻璃，Fresnel 与高光都不同）。

沿 PQ 复用它是近似。**量化一下为什么可以接受**：

| 层 | 典型 `cov` | 自身镜面 | 误差 |
|---|---|---|---|
| 玻璃 | 小（≈0.04，绝大多数是透射） | 有，且掠射时明显 | `cov` 小 ⇒ 权重小 |
| 粒子 / 火花 | 中~大 | 无（自发光，各向同性） | 可忽略 |
| 体积火 | 大 | 无（发射） | 可忽略 |

> 结论：**面纱是本文最弱的一环，但它是「有界」的最弱一环** —— 因为在 `cov` 大的地方，
> 层恰好没有镜面；在层有镜面的地方，`cov` 恰好很小。写进 known_issue §9.3，不要去修。

### 4.5 什么时候真的可以各向同性

| 项 | 条件 |
|---|---|
| 远景雾散射 | **永远**（不吃光，色是用户配的常数） |
| ambient / emission | **永远**（各向同性辐亮度） |
| 命中点漫反射 | 近似（Lambert，但含 AO / 环境光遮蔽的方向性残留） |
| 雾团在 g=0 时 | 可以（这正是今天的默认 `sun_phase_g=0.5` 的边界） |

## 5. 完整算式

### 5.1 符号

- `P, N, R`：着色点、法线、反射方向（视空间）；`s` = **屏幕像素**弧长；`t` = **世界米**。
- `σ_t = σ_a + σ_s`；`T(t) = exp(−∫₀ᵗ σ_t)`。
- `A ∈ [0,1]`：march 的置信度（命中 + 淡出/预算，沿用 #241 的 `a_out`）。

### 5.2 目标量

```
L_out(P) = L_med(0→s_end)                                   // 介质：永远积，与 A 无关
         + A · T(s_hit) · L_surf(hit; →P)                    // 表面：A 只乘这一项
         + (1−A) · T(s_end) · L_env(P, R, ρ)                 // 兜底：env 也只补表面项
```

再乘一次 Fresnel/AO（消费端做，模块不做）。

**⚠️ 与早前说法的修正**：曾经想过「A 乘整条积分」。那是错的 ——
`A→0` 的格子会连介质一起消失，在掠射淡出带上留下**一圈没有雾的黑边**；
反过来若介质不随 A 衰减而表面衰减，又会留下**一圈发光的雾**。
正解是把介质项**独立积分、两侧都有**（命中路与兜底路共享同一段介质），A 只削表面项。

### 5.3 前向累积（伪代码）

```cpp
// 单位换算：每像素对应的世界长度（掠射时变化极大，必须逐像素算）
float segLen = worldPerPixel(P, R);              // 米/像素
float T = 1.0f; Vec3f Lmed = 0, Lsurf = 0;
for (int i = 0; i < steps; ++i) {
    float s0 = i * ds, s1 = s0 + ds;
    Vec3f x0 = P + R * (s0 * segLen), x1 = P + R * (s1 * segLen);

    // ① 介质（三类来源各自精确/近似，见 §3.4）
    MediumSeg m = MediumSegment(x0, x1, /*rd=*/R);
    float cov  = 1.0f - exp(-m.dtau);
    Vec3f S    = m.S_iso + m.S_dir * phase(dot(R, -sunDir), g);   // ← 相位用 R
    Lmed += T * S * cov;
    T    *= exp(-m.dtau);

    // ② 面纱：穿过的透明等效层（只有 cov / Cavg / z̄，没有几何）——本版不做，保留为将来扩展点
    if (crossLayerDepth(s0, s1, layer.z_bar)) {
        Lmed += T * layer.Cavg * layer.cov;
        T    *= (1.0f - layer.cov);
    }

    // ③ 表面命中：深度图 + 厚度模型（沿用 #241）
    if (HitDepth(x1, T)) { Lsurf = T * ShadeHit(hit, /*towardP=*/ -R); T = 0; break; }
}
```

### 5.4 介质在 `MediumSegment` 里的分工（本版：只有水）

| 来源 | 实现对 | 相位 | 范围 |
|---|---|---|---|
| **水体** | 半空间闭式：`len = 与 y=level_y 的交段`，逐通道 `σa/σs` | `p(dot(R, −sunDir))`，**现算** | ✅ 精确 |
| 远景雾 | `Δτ = σ·w(mid)·len`，`S = color·(1−e^{−Δτ})` | 无（各向同性） | ⬜ 待确认 |
| 雾团 | — | — | ❌ 出范围（原方案：读 inject，按 §3.4 重标定） |

**射线穿水面**：水体是半空间，`y = level_y` 的交点解析可求，射线可能在水中进出一次 —— 
分成两段各自积分即可（不需要采样）。注意：**水皮自己不是介质**，它是表面项（若射线命中水面，
按 §4.3 走表面项，且只出解析太阳的像 + 探针，**不再弹射**，否则就是递归）。

## 6. 契约（逐条，实现时照抄）

1. **源不含镜面**：`diffuse-only` 颜色里不得含 env 镜面、PBR 镜面、Fresnel。
   **本版没有例外**（面纱已出范围，§4.4）。
2. **方向口径唯一**：任何方向依赖量，模块内只用 PQ 自身的方向求值（`p(R)`、`f_s(−R)`、`reflect(−R,N)`）。
3. **模块不分配/不读历史**：无 TAA、无抖动、无自身输出回读（沿用 #241 契约 5/6）。
4. **A 只作用于表面项**，介质项两侧都积（§5.2）。
5. **Fresnel / AO / 任何"乘一次"的量归消费端**：模块输出纯辐亮度，不乘 `F0·A+B`。
6. **env 只有一份**：命中点探针项必须 include `src/env_specular.h` 的同一份 GLSL，禁止重写；
   由 P4 的对拍测试锁一致性。
7. **单位双轨必须显式命名**：`s_*` = 屏幕像素，`t_*` = 世界米。**禁止混用**。
   （现存旧代码里 `|PQ| ≡ σ` 是**像素**，这一条会牵动 march 循环与每一条淡出常量。）
8. **水皮是解析靶子，不是屏幕空间靶子**：不进深度图、不写 WBO、命中即终止（不折射、不弹射）。
9. **顺序规则**：水皮命中与深度命中按距离比较（§3.5.2）。
10. **成本可解析界定**：每像素 ≤ `steps` 次介质求值 + 1 次深度命中判据 + 1 次水皮求交，与场景几何无关。
11. **丢弃可观测**：query 超出上限（top-1）、水皮求交不收敛、介质缺数据 —— 都要计数，不静默。
12. **任何透明层的合成结果都不具备几何**（即使本版不读）：不接受、不推断、不缓存任何
    透明层的法线/逐层深度（§3.2）—— 这条是长期约束，不随本版幅度失效。

## 8. 计算问题清单（坑，按严重度）

| # | 问题 | 处理 |
|---|---|---|
| 8.1 | **froxel 不是体积场**（相机射线累积，tile 中心） | 长度重标定（§3.4）；误差写 known_issue；不要假装有 3D 场 |
| 8.2 | **像素/米双参数化** | 显式命名 + 逐像素 `segLen`；所有 fade 常量标注单位 |
| 8.3 | **掠射 `segLen` 爆炸** | 射线起点的世界偏移按 `segLen` 取，不按固定米；`dFdx` 类量一律用未夹地平线的方向 |
| 8.4 | **自交** | 起点沿 R 偏一个像素（`P + R·(1·segLen)`），沿用 #241 的 slab 门控 |
| 8.5 | **半分辨率滤波与介质项** | 介质是低频、表面是高频：滤波器应把两者分开处理（介质先积、再滤波表面），否则 à-trous 会把雾抹到剪影外 |

## 9. known_issue

- **§9.1 水皮不做折射、不做水下相机**（§3.5.4b/c）：反射里的水下内容不存在（命中水皮即终止）。
- **§9.2 水皮的日像足迹是代理**（§3.5.4a）：解析命中点没有像素导数。
- **§9.3 介质只有水**：反射里没有雾团、粒子、火、玻璃（§2.3）—— 这不是 bug，是本版范围。
- **§9.4 命中点探针是「第二跳的环境光」**：不是真 GI，粗糙面的能量偏保守。
- **§9.5 无多次弹射**：金属互相反射会偏暗（一次弹射的固有代价）。
- **§9.6 屏幕外内容仍然不存在**（沿用 #241 §10）。
- **§9.7 单 query/像素**。
- **§9.8 波浪 vs 介质高度不一致**（沿用水体 known_issue §10.12）。

## 10. 与现有模块的边界

| 模块 | SSRV2 从它拿 | SSRV2 不给它 |
|---|---|---|
| `object3d` / `instanced` / `skeleton` | 深度、法线、F0/rough、**diffuse-only 色** | 不改它们的着色 |
| `wbo` / `particles` / `volume_fire` / 玻璃 | **不读** | 不要求它们任何改动 |

> 本版边界极简：**只新增两个读取者**（水体的 `WaterCommand` 参数、水皮的 `water_wave_math`），
> 不向任何现有生产者提要求 —— 这是 2026-11-23 削减范围后的直接收益。
| `fog` | 远景雾参数（⬜ 待定）；雾团 **不读** | 不改 inject（本版不动 fog 模块） |
| `water` | `σa/σs/phase_g/level_y/ior` | 不改水皮管线 |
| `env_specular` | 共享 GLSL 片段（命中点探针） | 不写第二份 |
| `ssr`（#241） | 深度命中判据、厚度模型、A 淡出、滤波器 | 不沿用它的「替换估计器」定位 |
