## 1. 目标与边界

### 1.1 要解决什么问题

**Tripo 生成的衣服模型「贴合」到特定人体 mesh 的过程。** 软体模拟器是这一过程的
**一个组件**：

1. 先把衣物**大致对准**人体（不属于本模块）；
2. 依靠几种力让衣物**被人撑开后靠弹力达到稳态**（**本模块的职责**）。

### 1.2 三类力

| # | 机制 | 说明 |
|---|---|---|
| 1 | **人体排斥** | 投影排斥：把侵入人体的顶点**直接顶到人体表面**。**期间不额外注入动能**（纯位置投影）。 |
| 2 | **衣物顶点间** | 抗拉伸 + 抗挤压 + 自动形状恢复（同一套力场，见 §2）。 |
| 3 | **重力** | 可选（滑条）。 |

### 1.3 明确不做的事（边界）

- ❌ **不做自动归一化**（不做 `F ∝ 1/√N`、不做面积定标、不做拓扑自适应）。
  **理由（Danis 定）**：自动归一化需要「K ∝ √N」等**多层假设**，在新资产上是否成立
  无法保证；**擅自替用户归一化会让人不舒服**。改成**用户知道「高模更硬，就手动降 F」**，
  其余交给滑条——**人肉闭环永远有效**。
- ❌ **不做断链**（撕开后力不单调的行为）。穿衣场景不需要。
- ❌ **不承诺无条件稳定**（见 §4）。
- ❌ 不支持宽松衣物的大幅褶皱（力场含抗扭转，布料偏硬，见 §2.4）。

### 1.4 验收边界

- **建模要求 T-pose**（Danis 明确接受「袖子抬不起来」）。
- 适用范围：**T-pose + 常规网格密度**。
- **已知病态区**：`M_total` 很小（如 1kg）+ 顶点数极大（如 200 万点）。见 §4.3。

## 2. 力场定义（**Danis 定稿，不改**）

### 2.1 关联邻居（仿真前一次性建立，之后不变）

```
对每个顶点 v_i，记录所有满足 |v_j - v_i| <= d 的顶点 v_j
    → nb_list[i] = { j : |v_j(0) - v_i(0)| <= d }
```

- **无论是否拓扑相连**（纯欧氏距离，不看索引/边）。
- **在 t=0 一次性定死，仿真过程中永不更新。**

> ⚠️ 「不更新」是刻意的：避免动态拓扑带来的 bug。后果见 §2.5（力会无限增长，
> 所以必须有截断）。

### 2.2 初始位移

```
pij(0) = v_j(0) - v_i(0)
```

### 2.3 力的公式

```
Fij = -[pij(t) - pij(0)] * F / max(|pij(0)|, d/10)
```

**逐项说明**：

- `pij(t) - pij(0)` —— 位移矢量相对初始的**变化量**。方向敏感（矢量而非标量），
  因此**隐含抗扭转**（见 §2.4）。
- `F` —— **力系数**。**量纲 = 力（N）**。物理含义：
  「**压缩比 1.0（压扁到零）时产生的力**」。
  乘号右边的比值 `Δp/max(...)` **无量纲**，即**压缩比**。
- `max(|pij(0)|, d/10)` —— 分母 clamp，**短边刚度上界保护**。
  防止极短关联（加密后可能出现）导致 `k_eff = F/|pij(0)|` 爆炸。

**等效刚度**（把力写成 `F = -k_eff · Δp` 的形式）：`k_eff = F / max(|pij(0)|, d/10)`。

### 2.4 隐含的抗扭转（重要，且是代价）

因为 `pij` 是**矢量**，当 j 绕 i 转动时 `|pij|` 不变但 `Δp ≠ 0`，**会产生恢复力** ——
这就是 ARAP 意义上的**抗扭转**。这是**有益的**（自动形状恢复），但代价是：

> **布料不能自由弯曲。** 袖子想弯，力场会对抗；宽松衣物会偏「硬壳感」。

对**贴体衣物**这是优点（自动回正）。Danis 已接受此约束（T-pose 建模）。

### 2.5 力的截断（**必须**，因为 §2.1 的关系不更新）

```
Fij = clamp(Fij, -F_max, +F_max),    F_max = 20 N （绝对值）
```

**为什么必须截断**：`nb_list` 永不更新 ⇒ 若 j 被撑到极远，`|Δp|` 线性增长 ⇒
`|Fij|` 线性增长、**没有上限** ⇒ 数值灾难。

**为什么 `F_max` 用「绝对力值」而非「倍数」**：

- 倍数形式（`F_max = ε·F`）在**密集网格**下会失效：`F` 变形后的临界倍数
  `∝ 每顶点质量 m`，`m` 一小就超标（见 §4.3 实算）。
- **绝对 20 N** 的语义是「**兜底**」：正常工况的力只有 ~0.3 N（低两个数量级），
  **截断根本不触发**；只有当顶点被拉到极远、力疯长时才被 20 N 挡住。
  这**正符合 Danis 原始意图**（「撕开后力量过大可以截断」）。

**不做断链**（Danis 定）：穿衣场景不需要「撕开后力不单调」的行为。
（注：不做断链时 `Fij` 关于 `Δp` 本就是**单调**的；Danis 记忆中的「不单调」是把
断链方案记混了。）

## 3. 离散化：质量、加密、积分

### 3.1 质量（按总质量均分）

```
m = M_total / N        （N = 参与仿真的顶点总数，含虚拟顶点）
```

- `M_total` 由**用户按生活经验给**（滑条）。
- **质量下限 1 kg**（护栏，防止数值病态）。
- Danis 的原始洞察（竖链推导）：**若顶点质量恒为 1，则网格越密总质量越大、
  自重越大、越容易被压垮** —— 所以必须「总质量守恒 + 按顶点均分」。

### 3.2 长边加密

```
任何 |edge| > d * 0.9 的边 → 中间等距插入虚拟顶点，使顶点间距 <= d * 0.9
```

**目的**：避免长边两端顶点「距离 > d」而不在任何 `nb_list` 里（关联断裂）。

**虚拟顶点的地位**（Danis 定）：

| 方面 | 虚拟顶点 | 说明 |
|---|---|---|
| 参与仿真 | **与原始顶点完全一样** | 同质量、同受力、同被投影排斥 |
| 提取变形 mesh | **只用原始顶点** | 虚拟顶点不输出 |

### 3.3 积分器（Danis 定稿，**签字**）

**Leapfrog + 对称阻尼**：

```
v_half  = v(t) * exp(-k*dt/2) + a(t) * dt/2
x(t+dt) = x(t) + v_half * dt
a(t+dt) = F(x(t+dt)) / m
v(t+dt) = (v_half + a(t+dt) * dt/2) * exp(-k*dt/2)
```

- 阻尼**对称地劈成两半**，包在 leapfrog 外侧。
- 符号误差 `O(dt²)`，与标准 leapfrog 同阶。

> **🖊️ 签字条款（Danis 2026-09-24 同意此表述）**：
> **本积分器「不承诺无条件稳定」。** 稳定性条件为 `dt_sub < 2/ω_max`，
> `ω_max = sqrt(max(k_eff)/m)`。阻尼只提供耗散，**不抬高稳定域上界**。
> 在实测的 `d / F / M_total / dt` 组合下若未观测到发散即视为通过。
> **若换更大 `F` 或更小 `d`，需重新实测。**

（James 曾要求「证明不发散」→ Danis 驳回：「99% 不发散能穿衣服就好」。
此决策记录在案，供后人理解这是**已知的工程赌注**，而非实现怀疑点。）

### 3.4 子步（暴力解，Danis 定）

```
dt = 1/60 s（外部时钟）
30 个子步 → dt_sub = 1/(60*30) = 5.5556e-4 s
```

## 4. 稳定性核算（James 算，Danis 认可）

### 4.1 最恶劣工况

| 参数 | 值 |
|---|---|
| `M_total` | 1 kg（下限） |
| `N` | 2,000,000 |
| `m = M/N` | 5e-7 kg |
| `d` | 0.1 m |
| 分母 clamp | d/10 = 0.01 m |
| `dt_sub` | 5.5556e-4 s |

**临界截断值**（力撞截断时刚度最大，`k_eff,max = F_max/0.01 = 100·F_max`）：

```
dt_sub < 2*sqrt(m/k_eff,max)
5.5556e-4 < 2*sqrt(5e-7/(100*F_max))
→ F_max,crit ≈ 64.8 N
```

取 **3× 安全裕度 → 21.6 N → 圆整 F_max = 20 N**。

### 4.2 正常工况下截断不触发（证明 §2.5 的设计意图）

| 工况 | `F` | 正常工作力 | vs `F_max=20N` |
|---|---|---|---|
| 200kg / 20000 点 | ≈0.3 N | ~0.3 N | **低两个数量级 → 不触发** ✓ |
| 顶点被拉到 10× | 0.3 N | ~3 N | 不触发（合理） |
| 顶点被拉到 100× | 0.3 N | ~30 N | **触发截断** ✓（兜底生效） |

### 4.3 已知病态区

**临界 `F_max` 正比于每顶点质量 `m`**：

- `m = 0.01`（200kg / 2万点）→ 临界 ~21.6 N ✓
- `m = 0.001`（200kg / 20万点）→ 临界 ~2.16 N ⚠️
- `m = 5e-7`（1kg / 200万点）→ 临界 ~0.001 N 🔴

**含义**：`M_total` 很小 + `N` 很大时，`m` 极小 ⇒ 每顶点惯性极小 ⇒ 局部频率极高 ⇒
`dt_sub` 不够。

**处理**：**不引入自适应**（Danis 定：先别加复杂度）。改为：

- UI/文档给出**死线提示**：`N / M_total <= 3e5 顶点/kg`（即每顶点质量 `>= 3.3e-6 kg`）；
- 超出时给 **WARNING**（不 crash，交给用户判断）。

### 4.4 稳定性旋钮

由 `ω_max = sqrt(k_eff,max/m)`、`k_eff,max = F/max(|pij(0)|, d/10)` 可知：

- **`d` 越小越危险**（分母 clamp 变小 → `k_eff` 变大）。`d=0.1` 安全裕度充足。
- **`F` 越大越危险**（线性）。
- **`m` 越小越危险**（见 §4.3）。

## 5. 参数表（**最终版**）

| 参数 | 形式 | 范围 / 默认 | 说明 |
|---|---|---|---|
| `M_total` 总质量 | **滑条** | 下限 1 kg | 用户按生活经验给 |
| `F` 力系数 | **滑条（指数坐标）** | **0.01 ~ 20 N** | 高模更硬 → 用户手动降 F |
| `g` 重力 | **滑条** | 可选（0 = 关） | |
| `k` 阻尼 | **滑条** | 1/s | 线性阻尼，纯时间属性 |
| `d` 关联距离 | **初始全局给（非滑条）** | 0.1 m | 决定 nb_list |
| `F_max` 截断 | **常数** | 20 N | 绝对值，兜底 |
| 子步数 | **常数** | 30 | |

> **为什么 `F` 用指数坐标**：`0.01 ~ 20 N` 跨 **3 个数量级**，线性滑条无法有效操控。
> 指数（对数）映射让低端（高模需要的 `0.01~0.3`）也有足够分辨率。

## 6. 接口契约（`Step(mesh, dt) -> 新 mesh`）

```
jpov::MeshData Simulator::Step(double dt);
```

- **输入 mesh 只读**；物理状态全部封在类内部（查看器不持有任何物理状态）。
- `dt > 0`，`CHECK` 崩溃（静默跳帧会掩盖时钟 bug）。
- 前置条件：`Init(mesh)` 必须先调用。
- 返回**按值**的新 mesh（含原始顶点；虚拟顶点不出现在输出里，见 §3.2）。
- 单位铁律：长度 = **米**，时间 = **秒**。资产换算在 gltf 加载边界完成。

**必须写成的单测**（纯 CPU、可静态验证）：

1. **`Σ Fij = 0`**（关重力 + 关阻尼）：力场对整体平移的净力为零
   —— 验证力场自洽/守恒。**⚠️ 只有关重力关阻尼时成立**（有重力时平移会加速；
   有阻尼时平移会减速）。
2. **截断生效**：构造 `|Δp|` 极大的关联，断言 `|Fij| == F_max`。
3. **虚拟顶点不作为输出**：加密后 Step 输出的顶点数 == 原始网格顶点数。
4. **M0 恒等语义回归**（已存在，见 `soft_mesh_simulator_test.cc`）。

## 3.5 实现现状（as-built，与 §3.3 的差异记录）

> 本节记录**代码实际怎么写的**，凡与 §3.3 字面有出入的地方都在此说明。
> 2026-09-25 起，Danis 把「积分器」拆成两步走：**先只接重力 + 速度衰减**
> （本阶段 M2），确认积分器本身正确后，再接顶点间力场。

### M2 已实现（`soft_mesh_simulator.cc`）

- **积分器**：完全按 §3.3 的「leapfrog + 对称阻尼」公式逐子步执行，无改动。
- **子步数**：`kSubsteps = 30`（§3.4）。
- **阻尼系数**：`kVelocityDamping = 0.1 (1/s)`，**当前为编译期常量**（尚非滑条）。
- **重力**：`kDefaultGravity = 9.8 m/s²`，方向 **-Y**；滑条范围 `[1, 20]`（§5 只
  写了「可选，0 = 关」；本阶段把下限提到 1，因为只做重力时 0 会退化成无意义的
  匀速直线。将来要「关重力」应由调用方显式表达，而非把 0 当魔法值）。
- **速度数组**：新增 `sim_velocities_`，与 `sim_positions_` 同序同长；`Init`/`Reset`
  时清零。
- **外力**：`a(t) = a(t+dt) = (0, -g, 0)`（常量）——因为本阶段**唯一外力是重力**，
  与位置无关。**接入弹簧力场后，第二个 `a` 必须改成 `F(x(t+dt))/m`**（§3.3 原式），
  代码注释已标注此点。
- **提取**：`ExtractMesh()` 把前 `vertex_count_` 个仿真点位置写回 `mesh_.positions`；
  虚拟顶点不输出（§3.2）。

### 已知的离散化差异（重要，防止误认为「实现等价于连续解」）

- 子步切分**不是**与原步数学等价：`sub=1` 与 `sub=30` 的一步结果相差 `O(dt²)` 量级
  （实测：单步 y 差约 5.5e-7 相对量）。子步是**稳定性/精度**手段，不是恒等变换。
- 终速的离散稳态为 `v_term = g·dt_sub·e/(1-e²)`，`e = exp(-k·dt_sub/2)`；
  在 `k·dt_sub << 1` 下 `v_term ≈ g/k`（`k=0.1` → 98 m/s）。单测以此锚定。

## 8. 附：讨论过但**已否决**的方案（留档，别再提）

| 方案 | 否决原因 |
|---|---|
| `F ∝ 1/√N` 自动归一化 | Danis：假设太多、不够官方、擅自归一化让用户不舒服 → 改成滑条 |
